# 07 — 管理员删除用户（独立任务）

> 父文档：[README.md](./README.md)
>
> 此功能用于清理历史遗留用户（开启邀请注册前的无邀请人用户），同时也是日常运维所需的常规能力。

---

## 一、需求

管理员后台用户列表新增「**彻底删除**」按钮，删除时级联清理：
- 该用户的所有日志（log）
- 该用户的所有 Token
- 该用户的所有充值记录（topup）
- 该用户作为邀请人/被邀请人的返利记录
- **被该用户邀请的下级用户，将其 `inviter_id` 置 0**（避免悬空引用）
- OAuth 绑定记录、订阅记录、签到记录等

## 三、实施方案

### 3.1 后端

#### 3.1.1 新增「硬删除」函数

**文件**：`model/user.go` 追加：

```go
// HardDeleteUserById 彻底删除用户及关联数据（事务）
func HardDeleteUserById(userId int) error {
    if userId <= 0 {
        return errors.New("非法用户ID")
    }
    return DB.Transaction(func(tx *gorm.DB) error {
        // 1. 解除下级用户的邀请关系（防悬空）
        if err := tx.Model(&User{}).Where("inviter_id = ?", userId).
            Update("inviter_id", 0).Error; err != nil {
            return err
        }

        // 2. 删除返利记录（作为邀请人或被邀请人）
        if err := tx.Where("inviter_id = ? OR invitee_id = ?", userId, userId).
            Delete(&AffRebateRecord{}).Error; err != nil {
            return err
        }

        // 3. 删除 Token
        if err := tx.Where("user_id = ?", userId).Delete(&Token{}).Error; err != nil {
            return err
        }

        // 4. 删除充值记录
        if err := tx.Where("user_id = ?", userId).Delete(&TopUp{}).Error; err != nil {
            return err
        }

        // 5. 删除 OAuth 绑定（如表存在）
        if err := tx.Where("user_id = ?", userId).Delete(&UserOAuthBinding{}).Error; err != nil {
            return err
        }

        // 6. 删除订阅相关
        _ = tx.Where("user_id = ?", userId).Delete(&UserSubscription{}).Error
        _ = tx.Where("user_id = ?", userId).Delete(&SubscriptionOrder{}).Error
        _ = tx.Where("user_id = ?", userId).Delete(&SubscriptionPreConsumeRecord{}).Error

        // 7. 删除签到、2FA、Passkey
        _ = tx.Where("user_id = ?", userId).Delete(&Checkin{}).Error
        _ = tx.Where("user_id = ?", userId).Delete(&TwoFA{}).Error
        _ = tx.Where("user_id = ?", userId).Delete(&TwoFABackupCode{}).Error
        _ = tx.Where("user_id = ?", userId).Delete(&PasskeyCredential{}).Error

        // 8. 删除日志（注意：可能在独立的 LOG_DB）
        if LOG_DB != DB {
            // 跨库无法用同一事务，单独执行
        }

        // 9. 硬删除用户本身（Unscoped 跳过软删除）
        if err := tx.Unscoped().Delete(&User{}, userId).Error; err != nil {
            return err
        }
        return nil
    })
}

// 日志删除（如 LOG_DB 与 DB 分离，单独清理）
func HardDeleteUserLogsById(userId int) error {
    return LOG_DB.Where("user_id = ?", userId).Delete(&Log{}).Error
}
```

#### 3.1.2 Controller

**文件**：`controller/user.go` 追加：

```go
// HardDeleteUser 管理员硬删除用户
func HardDeleteUser(c *gin.Context) {
    idStr := c.Param("id")
    userId, err := strconv.Atoi(idStr)
    if err != nil {
        common.ApiError(c, errors.New("用户ID非法"))
        return
    }

    // 安全检查：不能删除自己
    operatorId := c.GetInt("id")
    if userId == operatorId {
        common.ApiError(c, errors.New("不能删除当前登录的管理员账号"))
        return
    }

    // 安全检查：不能删除 root
    target, err := model.GetUserById(userId, false)
    if err != nil {
        common.ApiError(c, err)
        return
    }
    if target.Role == common.RoleRootUser {
        common.ApiError(c, errors.New("不能删除根管理员"))
        return
    }

    // 执行硬删除
    if err := model.HardDeleteUserById(userId); err != nil {
        common.ApiError(c, err)
        return
    }
    // 跨库日志清理
    _ = model.HardDeleteUserLogsById(userId)

    common.ApiSuccess(c, gin.H{"id": userId})
}
```

#### 3.1.3 路由

```go
// router/api-router.go adminRoute 下
adminRoute.DELETE("/hard/:id", controller.HardDeleteUser)
```

> 注意路径不能与现有 `DELETE /user/:id`（软删除）冲突，因此使用 `/hard/:id` 子路径。

## 四、批量清理（清理历史用户）

### 4.1 SQL 脚本（管理员手动执行）

清理「2026-05-10 前注册且无邀请人」的用户：

```sql
-- 先确认要清理的用户数量
SELECT COUNT(*) FROM users
WHERE inviter_id = 0
  AND created_at < UNIX_TIMESTAMP('2026-05-10 00:00:00')
  AND role = 1;  -- 仅普通用户

-- ⚠️ 谨慎：实际删除前先备份
```

如需批量删除，建议：

## 五、安全考虑

| 风险 | 缓解措施 |
|------|---------|
| 误删管理员 | 后端校验：禁止删除 root 角色 |
| 误删自己 | 后端校验：禁止删除当前登录用户 |
| 删除后无法恢复 | 前端二次确认（输入用户名） |
| 大批量删除导致 DB 锁 | 单次只删一个用户，事务粒度小 |
| 跨库（LOG_DB）数据残留 | 单独执行日志清理（容错处理） |
| 删除引发外键错误 | 使用事务 + 按依赖顺序删除（先子后父） |
