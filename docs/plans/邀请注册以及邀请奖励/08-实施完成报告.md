# 邀请注册与邀请奖励 — 实施完成报告

**日期**: 2026-05-10
**状态**: 前端已完成，后端已完成，待用户验证

---

## 一、实施概述

本次功能实现了完整的邀请注册和邀请返利系统，包括：

- 用户通过邀请链接注册时自动绑定邀请关系
- 被邀请用户充值后，邀请人获得按比例的返利积分
- 返利设置可待结算期后自动结算到邀请人账户
- 邀请人可将返利额度转入余额
- 管理员可查看邀请返利报表及配置返利参数

## 二、后端实施

### 2.1 新增数据库表

#### `aff_relationships` — 邀请关系表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uint | 主键 |
| inviter_id | uint | 邀请人用户 ID |
| invitee_id | uint | 被邀请人用户 ID |
| created_at | int64 | 绑定时间（Unix 秒） |

- 唯一索引: `(invitee_id)` — 每个用户只有一个邀请人
- 索引: `(inviter_id)` — 按邀请人查询

#### `aff_rebates` — 返利记录表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uint | 主键 |
| inviter_id | uint | 获得返利的邀请人 ID |
| invitee_id | uint | 触发返利的被邀请人 ID |
| rebate_quota | int64 | 返利金额（Quota 单位） |
| source_quota | int64 | 原始充值金额 |
| status | string | pending / settled / cancelled |
| created_at | int64 | 创建时间 |
| settle_at | int64 | 预计结算时间 |
| settled_at | int64 | 实际结算时间（0=未结算） |

- 索引: `(inviter_id, status)`, `(settle_at)`, `(status)`

### 2.2 用户表扩展

`users` 表新增字段：
| 字段 | 类型 | 说明 |
|------|------|------|
| aff_code | string | 用户专属邀请码（6位随机字母数字）|
| aff_quota | int64 | 可用返利余额 |
| aff_pending_quota | int64 | 待结算返利余额 |
| aff_history_quota | int64 | 历史累计返利 |
| aff_count | int | 成功邀请人数 |

### 2.3 系统配置项（Options）

| Key | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| AffRegisterRequired | bool | false | 注册是否必须邀请码 |
| AffRebateEnabled | bool | true | 是否开启充值返利 |
| AffRebateRatio | float64 | 0.10 | 返利比例 (0-1) |
| AffRebateWaitDays | int | 30 | 待结算天数 |

### 2.4 新增文件

#### 模型层 (`model/`)
- `model/aff.go` — `AffRelationship`、`AffRebate` struct 定义及 GORM hook
- `model/aff_crud.go` — 数据库 CRUD 操作：
  - `CreateAffRelationship()` — 创建邀请关系
  - `GetAffRelationshipByInvitee()` — 按被邀请人查询关系
  - `GetAffInvitees()` — 分页查询邀请人的被邀请列表
  - `CreateAffRebate()` — 创建返利记录
  - `GetAffRebates()` — 分页查询返利记录
  - `SettleAffRebates()` — 结算到期的 pending 返利（批量）
  - `TransferAffQuota()` — 将返利余额转入用户 quota
  - `GetAffReport()` — 管理员统计报表
  - `GetAffStats()` — 用户个人统计

#### 服务层 (`service/`)
- `service/aff_service.go` — 业务逻辑：
  - `BindAffCode()` — 注册时绑定邀请码
  - `GenerateAffCode()` — 生成唯一邀请码
  - `ProcessAffRebate()` — 充值成功后触发返利（供 hook 调用）
  - `SettleAffRebates()` — 定时结算任务入口
  - `TransferAffQuota()` — 返利转余额
- `service/aff_hook.go` — hook 注册避免循环依赖：
  ```go
  var AffRebateHookFn func(userId int, quota int64) error

  func init() {
      AffRebateHookFn = ProcessAffRebate
  }
  ```

#### 控制器层 (`controller/`)
- `controller/aff_controller.go` — HTTP 处理器：
  - `GET /api/user/aff/stats` — 用户返利统计
  - `GET /api/user/aff/invitees` — 邀请列表（分页）
  - `GET /api/user/aff/rebates` — 返利明细（分页）
  - `POST /api/user/aff/transfer` — 返利转余额
  - `GET /api/user/aff/check-code` — 验证邀请码
  - `GET /api/admin/aff/report` — 管理员统计报表

#### 路由注册 (`router/`)
- 在 `router/api.go` 中注册用户路由（`/api/user/aff/*`，需认证）
- 在 `router/api.go` 中注册管理员路由（`/api/admin/aff/*`，需管理员权限）

#### 定时任务 (`service/task.go` 或新增 `service/aff_task.go`)
- 每小时执行 `SettleAffRebates()` 结算到期返利

#### 注册流程集成 (`service/user_service.go`)
- 注册成功后调用 `BindAffCode(userId, affCode)` 绑定邀请关系

#### 充值流程集成
- 充值成功后调用 `service.AffRebateHookFn(userId, quota)` 触发返利
