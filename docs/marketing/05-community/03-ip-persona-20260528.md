# IP人设与内容定位手册

> 适用范围：微信群日常运营 + 公众号/小红书/抖音多平台内容输出

---

## 一、IP定位：技术测评派

### 人设核心标签

| 维度 | 定义 |
|------|------|
| **身份** | 独立开发者 / AI工具重度用户，自己在用这些工具写代码、做项目 |
| **性格** | 直接、有观点、不废话，说好说坏都有数据支撑 |
| **专长** | AI编程工具横评、API费用优化、工具配置实战 |
| **视角** | "我测了，告诉你结论" + "这个坑我踩过，你别踩" |
| **立场** | 不捧任何工具，只说用哪个划算、哪个场景适合哪个 |

### 人设一句话

> **"帮你把AI工具用好、用便宜的那个人。"**

### 与中转站的关系（对外口径）

不要说"我是中转站的运营"，而是说：
- "我自己在用LLM-Link，觉得不错所以推荐给大家"
- "这是我目前用下来性价比最好的方案"
- 偶尔透露"我也参与了这个平台的推广"即可，不必刻意隐瞒也不必主动声明

## 二、内容三大支柱

```
         ┌─────────────────────────────────────┐
         │           内容三大支柱               │
         └──────┬──────────┬──────────┬────────┘
                │          │          │
         ┌──────▼──────┐ ┌─▼────────┐ ┌▼──────────────┐
         │  A. 工具干货  │ │B. 对比测评│ │ C. 省钱实战   │
         │  (信任建立)  │ │(有观点)  │ │ (软植入中转)  │
         │   占比 50%   │ │ 占比 30% │ │   占比 20%   │
         └─────────────┘ └──────────┘ └──────────────┘
```

### A类：工具干货（50%）— 不提中转站

纯分享，建立专业信任。读者看完有收获，自然关注。

**选题方向：**
- Claude 隐藏功能（extended thinking / 长上下文技巧）
- GPT-4o 冷门用法（图像识别/语音/函数调用）
- Gemini 2.5 Flash 免费额度怎么薅
- Cursor vs Windsurf vs Claude Code 实测对比
- AI提示词技巧（让输出质量翻倍的3个方法）
- 开发者工作流：AI工具怎么嵌入日常开发

**内容特征：**
- 有具体步骤/截图/数据
- 结论前置，细节在后
- 承认工具的局限，不无脑吹

---

### B类：对比测评（30%）— 间接提及中转

有观点的横评，中转站作为"方案之一"自然出现。

**选题方向：**
- 官方订阅 vs API按量计费，哪个更划算？
- 5家AI中转站横评（真实测试响应速度/模型真实性）
- Claude Code vs Cursor：重度用户用了3个月说真话
- AI编程工具成本大盘点（含官方+中转方案）
- 国内用Claude的几种方案对比

**内容特征：**
- 有评测维度，不是单方面夸
- LLM-Link作为"我最终选择"出现，而不是"赞助商"
- 说出竞品的优点，再说为什么没选它

---

### C类：省钱实战（20%）— 直接植入

有明确的"省钱方法"逻辑，中转站是解决方案的核心。

**选题方向：**
- 我用Claude Code每月花多少钱（账单公开）
- API中转站选对了能省多少？我的真实数据
- Claude Code配置教程（5分钟从官方切换到中转）
- 首充阶梯赠送活动解读：怎么充最合算

**内容特征：**
- 有具体金额/截图，真实感强
- 配置步骤完整，读完能操作
- 转化入口自然（注册链接在文末，不突兀）

## 三、各平台语言风格

### 微信群（日常话题）

- **风格**：聊天口吻，像跟朋友说话
- **长度**：100-300字，超过不发
- **结尾**：提问/引发讨论，不是广告语
- **频率**：每天1条，晚上8-10点发

**示例：**
```
今天测了一下Claude 3.7在处理长代码上下文时的表现，
发现一个有意思的现象：同样的prompt，上下文超过50k tokens
之后回复质量明显下降，但加了cache_control标记之后好多了。

有人也注意到这个问题吗？你们怎么处理的？
```

---

### 微信公众号（深度文章）

- **风格**：认真但不学术，像一篇有深度的朋友圈长文
- **长度**：1500-3000字
- **结构**：背景痛点 → 我的探索 → 结论/方案 → 行动指引
- **图片**：截图/数据图必须有，纯文字没人看
- **转化**：文末1个链接，不超过2个

---

### 小红书（图文笔记）

- **风格**：口语化，有共鸣感，"我也遇到过这个问题"
- **长度**：正文300-500字，配6-9张图
- **标题**：强烈情绪/数字/对比，如"省了¥2000！""3个月踩坑总结"
- **标签**：#Claude #AI编程 #程序员 #ChatGPT #AI工具
- **转化**：评论区置顶链接或引导私信

---

### 抖音/视频号（口播视频）

- **风格**：说话节奏快，每句话都有信息量，不废话
- **长度**：60-90秒，超过90秒掉粉
- **结构**：痛点3秒抓人 → 结论提前说 → 步骤演示 → 行动号召
- **字幕**：全程字幕，关键数字/结论加大加粗
- **转化**：主页链接 / 评论区置顶

**脚本节奏模板：**
```
0-3s：[痛点/悬念] "你知道用官方Claude Code一个月要花多少钱吗？"
3-8s：[结论前置] "我测了3个月，实际账单给你看"
8-50s：[核心内容] 3-4个核心信息点，每点配截图/操作演示
50-70s：[解决方案] "我现在用的方法是..."
70-85s：[行动号召] "主页有链接，有问题评论区聊"
```

## 四、内容合规红线

### 绝对不能说

- ❌ "稳定不跑路"（无法保证，说了就是坑）
- ❌ "永久有效""永久低价"
- ❌ "官方同款""官方授权"（没有就别说）
- ❌ 夸大省钱比例（要有真实数据支撑）
- ❌ 直接说"买我们的"（用"我在用的"代替）

### 必须注意

- ✅ 有活动条款时加"以控制台为准"
- ✅ 成本测算要注明假设条件（"中度用户""每天2小时"）
- ✅ 说竞品时只说客观事实，不人身攻击
- ✅ 涉及充值金额必须标注"首充"或"活动期"等限定条件

## 五、内容与运营的协同逻辑

```
公众号/小红书/抖音 发布软文
        ↓
在微信群分享文章链接 + 简短说明
        ↓
群内引发讨论（提问题 / 发表观点）
        ↓
感兴趣的用户私信或点击链接
        ↓
注册 → 首充 → 转介绍
```

**关键原则**：群是放大器，不是直接销售场所。内容先在外部平台有传播，再引入群，而不是群内直接推销。
