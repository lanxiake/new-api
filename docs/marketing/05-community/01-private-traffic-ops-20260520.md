| **技术群** | QQ 1102925294 | 技术交流、API 配置答疑、bug 反馈 | V2EX/掘金/CSDN/GitHub/技术博主 | 2000 人 |

## 二、微信群基础设置

### 建群与命名

- **群名**：`LLM-Link 新人交流群（{编号}）` — 不带"福利""优惠""免费"等敏感词
- **群主**：用一个**专门的运营小号**，不要用主号（防封号）
- **群公告**：见下文模板
- **群头像**：LLM-Link logo
- **群二维码**：每 6 天更换一次（微信群码 7 天失效），更换前发新码到旧群

### 群公告模板

```
欢迎来到 LLM-Link 新人交流群 🎉

📖 这里能解决你的问题
· Claude Code / Codex CLI 怎么配置
· AI 编程怎么省钱
· 中转站怎么避坑

🎁 新人福利
· 阶梯首充赠送：充 ¥50 送 20% / 充 ¥100 送 40% / 充 ¥200 送 60% / 充 ¥500 送 100%（到账 $1000，每用户限首充一次）
· 邀请朋友首充，立即奖 ¥10/人（30 天活动期）
· 注册：https://www.llm-link.top/register?aff=3Us3

📌 群规
1. 友好交流，禁止任何形式辱骂、广告、刷屏

### 群机器人配置（关键）

> 推荐：WeChatFerry / NGCBot / 微秘书 / Q 群机器人。免费方案够用。

**必配触发词**（关键词回复）：

| 触发词 | 自动回复 |
|--------|---------|
| `配置` / `怎么用` / `教程` | 发送 [接入教程](./articles.md#文章四教程型) 简化版 + 链接 |
| `价格` / `多少钱` | 发送活动卡片（阶梯首充赠送说明 + 模型价格表） |
| `充值` / `付款` | 发送充值说明（支付宝/微信、¥1=$1）+ 后台链接 |
| `邀请` / `返利` / `拉新` | 发送邀请始付始奖说明（见 [campaigns.md](./campaigns.md)） |
| `踩坑` / `跑路` / `安全` | 发送"少量充值"建议 + 邀请制说明 |
| `Cherry` / `Cline` / `Cursor` | 提示用 `default` 分组，附配置 |
| `404` / `401` / `报错` | 触发人工接手提示："运营即将处理，请耐心等待" |

**定时消息**（每天最多 1 条，避免骚扰）：

- 每天 20:00（仅工作日）：服务状态简报 + 1 条 [social-copy.md](./social-copy.md) 风格的轻话术
- 每周日 21:00：本周新增功能 / 价格调整通知（若有）

### 入群欢迎语（机器人自动发）

```

## 四、每日运营 SOP（30–60 分钟）

### 早间（10–15 分钟）

- [ ] 看两群昨晚至今未回复消息（机器人未触发的）
- [ ] 看后台：昨日新增注册、首充、邀请关系
- [ ] 把新付费用户的邀请人记下来 → 备发"邀请始付始奖 ¥10"

### 中午（5–10 分钟）

- [ ] 发一条群内话术（从 [social-copy.md](./social-copy.md) 选 #12 / #14 / #22 / #23）
- [ ] 回应群里技术问题

### 晚间（15–25 分钟）

- [ ] 主话题引导：每周固定 3 个晚上 21:00 发起小话题
  - 周一：晒账单 / 省钱小技巧
  - 周三：踩坑分享 / 工具组合
  - 周五：周末项目 / AI 副业
- [ ] 给当天首充用户邀请人手工发"始付始奖 ¥10"额度
- [ ] 更新当日数据表（见 paid-promotion-plan.md 第六节）

### 周日（额外 30 分钟）

- [ ] 周报：群消息数、新增、付费、CAC、爆款笔记
- [ ] 决定下周话术节奏 / 是否启动新活动

## 八、风险与红线

| 风险 | 应对 |
|------|------|
| 微信群被封 | ① 群主小号 ② 群名去敏感词 ③ 不发"充值""二维码"裸图 ④ 备份用户微信，封了重建立 |
| 群成员发竞品广告 | 警告 → 踢；不要在群里和对方对线 |
| 假首充刷返利 | 同一支付账号/同一邀请人短时间 ≥ 3 单 → 人工核查 |
| 群运营出错（错发额度） | 错发额度从备用预算扣除，记账留痕 |
| 运营离群 / 你休假 | 提前准备替班；机器人撑 1–2 天问题不大 |
