## 二、新增活动：邀请始付始奖 ¥10（本期核心）

### 规则设计

| 项目 | 内容 |
|------|------|
| 活动名称 | 邀请始付始奖 |
| 触发条件 | 被邀请人首次充值 ≥ ¥50 |
| 奖励 | 邀请人立即获得 ¥10 额度 |
| 到账时间 | **即时到账**（与现有 10% / 30 天返利并存） |
| 周期 | 30 天活动期（D1–D30） |
| 预算 | ¥300（30 人 × ¥10） |
| 后台实现 | **手工发放**（每天晚间运营查后台，手动给邀请人加额度） |

### 与现有返利的关系

```
用户 A 邀请用户 B → 用户 B 首充 ¥100
  ↓
用户 A 立即获得：¥10（邀请始付始奖，活动期专属）
用户 A 30 天后获得：¥10（10% 长期返利，平台标准）
  ↓
用户 A 总收益：¥20
```

> 两个机制并存，不冲突。"始付始奖"是 30 天活动期的额外激励，长期返利保持不变。

### 手工发放 SOP

**每天晚间 21:00**（运营固定时间）：

1. 登录后台 → 查看当日新增首充用户
2. 查询每个首充用户的邀请人（通过 aff 关系）
3. 筛选出"被邀请人首充 ≥ ¥50"的记录
4. 给邀请人账户手动增加 ¥10 额度
5. 记录到 `invite-reward-log.csv`（见下文）
6. 在群里 @ 邀请人通知："恭喜 @xxx，你邀请的朋友已首充，¥10 奖励已到账 🎉"

### 发放记录表（invite-reward-log.csv）

```csv
日期,邀请人ID,邀请人昵称,被邀请人ID,被邀请人首充金额,奖励金额,发放时间,备注
2026-05-25,1001,张三,1050,50,10,2026-05-25 21:05,正常
2026-05-26,1001,张三,1051,100,10,2026-05-26 21:03,同一邀请人第2单
2026-05-26,1002,李四,1052,50,10,2026-05-26 21:05,正常
...
```

> 30 天后汇总：总发放笔数、总金额、人均邀请数、裂变系数。

### 话术模板

**群公告 / 欢迎语**：
```
🎁 邀请朋友首充 ≥ ¥50，立即奖 ¥10 到你账户（30 天活动期）
```

**群内推广**：
```
提醒一下：现在邀请朋友注册并首充 ≥ ¥50，你立刻拿 ¥10 额度（不用等 30 天）。
邀请链接在控制台 → 邀请管理里复制。

邀请 5 个朋友首充 = ¥50 到手，相当于自己充值免费了。
```

**私聊催单**（针对已注册未首充的被邀请人）：
```

```

### daily-tracking.csv

```csv
日期,KOC编号,平台,笔记浏览,进群人数,注册人数,首充人数,首充总额,邀请奖发放笔数,邀请奖发放金额,当日现金支出,累计现金支出,累计付费用户,当日CAC,累计CAC
2026-05-25,xhs01,小红书,320,5,3,1,50,0,0,100,100,1,100,100
2026-05-26,xhs02,小红书,450,8,5,2,150,1,10,100,200,3,50,67
2026-05-27,xhs03,小红书,280,4,2,1,50,0,0,120,320,4,120,80
...
```

**关键指标计算**：
- 当日 CAC = 当日现金支出 / 当日首充人数
- 累计 CAC = 累计现金支出 / 累计付费用户
- 进群率 = 进群人数 / 笔记浏览 × 100%
- 付费率 = 首充人数 / 注册人数 × 100%

### 第 15 天中期复盘表

| 指标 | 目标 | 实际 | 达成率 | 决策 |
|------|------|------|--------|------|
| 累计付费用户 | ≥ 20 | ? | ? | 达成 → 维持；未达成 → 调整 |
| 累计 CAC | ≤ ¥50 | ? | ? | > ¥60 → 停损 |
| 进群率 | ≥ 60% | ? | ? | < 40% → 启动应急活动 |
| 付费率 | ≥ 30% | ? | ? | < 15% → 限时加码 |
| 爆款笔记数 | ≥ 2 | ? | ? | 续约爆款 KOC |
