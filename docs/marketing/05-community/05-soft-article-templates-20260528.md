# 软文模板库

> 共6类模板，对应内容日历中的A/B/C三类内容，适配公众号/小红书/抖音三个平台。
> 每个模板含：结构说明 + 段落提示 + 写作要点 + 标题公式

---

## A类模板（干货教程型）

### A1 — 公众号版：功能深度测评

**适用选题举例**
- Claude extended thinking深度测评
- GPT-4o图像识别10种用法
- Gemini 2.5免费额度使用指南

**标题公式**
```
《[工具名] [功能名]到底[多好用/多坑]？我测了[数量/时长]，结论是…》
《[工具名]的[N]个冷门功能，[目标用户]必须知道》
《我用[工具名]做[具体任务]，[结果/结论]》
```

**文章结构**

```
【开头：痛点/场景引入】（150字以内）
  - 描述一个读者熟悉的场景或困惑
  - 最后一句话引出"今天来聊这个功能"
  - 避免：大篇背景介绍、自我介绍

【第一部分：是什么】（200-300字）
  - 一句话定义这个功能
  - 它解决什么问题
  - 和其他功能/工具的区别

【第二部分：怎么用】（500-800字，核心部分）
  - 具体使用步骤（编号列表）
  - 必须有代码/截图/配置示例
  - 至少1个完整的实操案例
  - 注意事项/常见错误

【第三部分：实测结果】（300-400字）
  - 真实数据（速度/质量/成本）
  - 适合的场景 vs 不适合的场景
  - 与同类方案的横向比较（1-2句话）

【结尾：行动指引】（100字以内）
  - 一个明确的行动建议
  - 选填：引导进群/关注/留言
  - 避免：硬广、多个链接
```

**写作要点**
- 结论放在第一段，不让读者猜
- 每个步骤配截图，没有截图的步骤说服力减半
- 数据必须真实，估算要注明是估算
- 文末最多1个转化链接

### A2 — 小红书版：技巧分享卡片

**标题公式**
```
《让[工具名]输出质量翻倍的[N]个技巧｜[目标用户]必看》
《用了[时长]，[工具名]这[N]个功能我天天用》
《[场景]怎么用AI？[N]步搞定，亲测有效》
```

**内容结构（500字以内）**

```
【首图文字】（封面必须有大字）
  - 核心结论/数字，如"省了¥2000！""效率翻倍"
  - 字要大，背景简洁

【正文开头：一句共鸣】
  - "用[工具名]的时候是不是经常遇到…"
  - 或直接说"今天分享[N]个技巧"

【主体：技巧列表】（3-5个为佳）
  每个技巧：
  ✅ 技巧名（加emoji）
  → 一句话说是什么
  → 一句话说怎么用
  → 效果/省了什么

【结尾：互动引导】
  "你还有什么用法，评论区分享～"
  或"有问题私信我"

【标签】（放正文末尾）
  #Claude #AI编程 #程序员 #ChatGPT #AI工具 #效率工具
```

**写作要点**
- 每张配图都要有文字说明，不能纯截图
- 分点清晰，用emoji分隔，阅读不费力
- 语气像跟朋友聊天，不要"专业腔"

## B类模板（对比测评型）

### B1 — 公众号版：工具横评

**适用选题举例**
- Claude Code vs Cursor深度对比
- 5家AI中转站横评
- Gemini vs Claude最新对比

**标题公式**
```
《[A] vs [B]：用了[时长]，我的真实判断》
《[N]家[类型]横评：[维度1]/[维度2]/[维度3]，谁更值？》
《[场景]下，[A]和[B]差距有多大？数据说话》
```

**文章结构**

```
【开头：立场声明】（100字）
  - 说明你同时用过两者（建立可信度）
  - 说明评测维度（预设读者预期）
  - 不要一开始就说结论

【评测维度说明】（100字）
  - 列出本次评测的N个维度
  - 说明评测方法（用什么任务测、测多久）

【逐维度对比】（主体，每个维度200-300字）
  格式：
  ### 维度X：[维度名]
  [A的表现] — 配截图/数据
  [B的表现] — 配截图/数据
  **小结**：[这个维度谁更好，适合什么人]

【综合结论】（300字）
  - 分人群给建议，不要"谁更好"这种绝对结论
  - 我的最终选择是什么，为什么
  - 对方适合哪些人（不完全否定）

【结尾】（100字）
  - 引导评论（"你用的是哪个？"）
  - 选填：相关链接1个
```

**写作要点**
- 给对方（非选择方）留足够的正面评价，增加可信度
- 结论必须有"分人群"的差异化建议，不能一刀切
- 数据越具体越好（响应时间ms级别、token数量、实际费用）

### B2 — 小红书版：对比笔记

**标题公式**
```
《[A] or [B]？用了[时长]终于想明白了》
《[N]个维度对比[A]和[B]，[目标用户]看这一篇就够》
《踩过这[N]个坑，才选定了[工具名]》
```

**内容结构**

```
【首图】：两个工具的logo/截图对比

【开头】：
  "纠结[A]还是[B]的看过来，
  我两个都用了[时长]，说说真实感受"

【核心对比表】（最直观）：
  | 维度 | A | B |
  | 响应速度 | ⭐⭐⭐⭐ | ⭐⭐⭐ |
  | 价格 | 贵 | 便宜 |
  | 适合场景 | 后端 | 前端 |

【结论】：
  "我的选择是[X]，因为[一个理由]"
  "但如果你是[描述人群]，[Y]更适合你"

【互动】：
  "你用的是哪个？为啥？"
```

## C类模板（省钱植入型）

### C1 — 公众号版：账单/成本分析

**适用选题举例**
- 我的Claude API月账单公开
- AI工具成本优化完整指南
- 从官方订阅切换到API：省了多少

**标题公式**
```
《我用[工具名][时长]，花了多少钱？（真实账单）》
《AI工具成本优化：从[金额A]压到[金额B]，怎么做到的》
《[工具名]省钱指南：[N]个方法让成本降[比例]》
```

**文章结构**

```
【开头：真实账单/数据引入】（200字）
  - 直接展示账单截图（真实感最重要）
  - 说明使用强度（中度/重度，每天多少小时）
  - 对比基准（和官方订阅对比）

【第一部分：我的用法和需求】（300字）
  - 主要用途（Claude Code / 写作 / API开发等）
  - 使用频率
  - 对工具的核心需求（稳定性/价格/功能）

【第二部分：方案演进】（400字）
  - 第一阶段：用过什么，遇到什么问题
  - 第二阶段：怎么发现现在的方案
  - 第三阶段：切换后的效果
  （这一部分是软植入中转站的核心位置）

【第三部分：配置教程】（400字）
  - 具体步骤（有截图）
  - 注意事项
  - 常见问题解答

【第四部分：省钱建议】（200字）
  - 适合什么人
  - 不适合什么人（诚实建立信任）
  - 我的建议：先小额试用

【结尾】（100字）
  - 注册链接（1个，自然放置）
  - 引导评论：有问题留言/进群
```

**写作要点**
- 账单截图是最强的信任建立工具，必须有
- 植入中转站要以"我的方案"角度，不是"推广"角度
- 必须说"不适合的场景"，不能把中转站说成万能的
- 充值金额计算举例要真实，不夸大

### C2 — 小红书版：配置教程卡

**标题公式**
```
《Claude Code配置教程｜[N]分钟从官方切换到[中转]》
《省了¥[金额]！AI工具这样配才划算》
《[工具名]+[中转]配置全流程｜附避坑指南》
```

**内容结构**

```
【首图】：配置完成的截图 或 省钱数据对比图

【开头共鸣】：
  "用官方[工具名]是不是经常触发限速/要绑外国卡？
  分享我的解决方案，配置超简单"

【步骤列表】（4-6步，每步配截图）：
  Step 1：注册账号（[链接]）
  Step 2：创建Token
  Step 3：配置baseUrl
  Step 4：测试连接
  （附：常见报错解决）

【效果展示】：
  "配置完后实测速度/稳定性…"
  "这个月账单是¥xxx"

【注意事项】：
  "要注意选对分组，否则…"
  "建议先充小额试试"

【结尾互动】：
  "有问题评论区问我，或私信"
  #AI工具 #Claude #省钱 #程序员
```

### C3 — 抖音/视频号版：口播脚本

**标题公式（封面字幕）**
```
"用Claude一个月花多少钱？真实账单公开"
"AI工具省钱秘籍｜每月少花¥[金额]"
"[N]分钟配置好Claude Code中转"
```

**60-90秒口播脚本结构**

```
【0-3秒：痛点钩子】
  "你知道用Claude Code一个月要花多少钱吗？"
  "很多人用官方API第一个月账单直接给整不会了"
  （配字幕大字：¥2000+/月？）

【3-10秒：结论前置】
  "我用了3个月，账单给你看，
  现在每月只花¥[金额]，省了一大半"
  （配截图：账单截图）

【10-50秒：核心内容】（3个信息点）
  "第一个：为什么官方订阅不合算——"
  [配演示/截图]
  "第二个：API中转是什么——"
  [配演示/截图]  
  "第三个：怎么配置，5分钟搞定——"
  [配屏幕录制：配置步骤]

【50-70秒：结果验证】
  "配完之后我测了一下，速度和官方基本一样，
  账单直接少了一半"
  （配截图对比）

【70-85秒：行动号召】
  "想试的主页有链接，
  有问题评论区聊，我每条都回"
  （配字幕：主页链接）
```

**拍摄要点**
- 全程字幕，关键数字加大加红
- 节奏快，每2-3秒切一个信息点
- 不要说"广告""推广"，只说"我在用的方案"
- 封面图必须有大数字（省了多少钱）

## 跨平台内容改编指南

同一选题，如何适配不同平台：

| 原始内容 | 公众号版 | 小红书版 | 抖音版 |
|---------|---------|---------|-------|
| Claude测评 | 2000字深度文章 | 500字+9图卡片 | 60秒口播+截图 |
| 配置教程 | 图文步骤+代码 | 步骤截图卡片 | 屏幕录制 |
| 账单公开 | 完整成本分析 | 数字对比图 | 账单截图+口播 |
| 对比横评 | 多维度长文 | 对比表+结论 | 30秒核心结论 |

**改编原则**
1. 公众号：信息完整，有深度，适合深度阅读
2. 小红书：视觉优先，分点清晰，适合碎片浏览
3. 抖音：结论前置，节奏快，3秒不抓人就划走

**内容复用流程**
```
写公众号长文（核心内容源）
    ↓
提取3-5个关键点 → 改成小红书卡片
    ↓
提取最强结论+数据 → 写抖音口播脚本
    ↓
三个平台发布后 → 在微信群分享链接+50字简介
```
