**群消息：**
```
Claude Code有几个配置参数很多人没用到：

1. 设置自定义baseUrl（切换中转/官方）
   claude config set baseUrl https://xxx/v1

2. 调整默认模型
   claude config set model claude-opus-4-7

3. 开启详细日志（debug用）
   CLAUDE_CODE_DEBUG=1 claude

4. 设置最大token限制（防止单次消耗太多）
   claude config set maxTokens 4096

这几个参数配置好，能让Claude Code更稳定、更省钱。
```
