## 理论一：程序到底"跑"在哪里？

动手前，先建立一个常识——你做的程序，最终会"跑"在三个地方之一。搞懂这个，后面装工具、选方案才不会懵。

<!-- IMAGE:02 type=infographic path=images/02-platforms.png -->

![程序跑在哪里·三种运行平台](images/02-platforms.png)

**1. 桌面（你的电脑上）**
Windows / Mac / Linux。程序就装在你自己电脑里运行，像你平时用的 Word、微信。我们这个系列，**绝大多数练习都在你自己电脑上跑**，最简单、最可控。

**2. 网页（浏览器里）**
用 Chrome、Edge 这些浏览器打开就能用，不用安装。比如你刷的网站、在线文档。后面我们也会把工具升级成网页版。

**3. 手机（App / 小程序）**
苹果、安卓、鸿蒙上的 App，微信小程序也算这一类。门槛稍高，放到很后面再说。

**现在你只需记住一件事**：我们第一个工具，就跑在**你自己的电脑桌面上**。所以接下来要装的 Claude Code，也是装在你电脑里的一个工具。

## 理论二：CLI 是什么？别被"命令行"吓到

装 Claude Code 会用到一个东西，叫 **CLI**（命令行界面，Command-Line Interface）。这是新手第一个心理障碍，我必须先帮你拆掉。

<!-- IMAGE:03 type=infographic path=images/03-cli.png -->

![CLI 是什么](images/03-cli.png)

你平时用电脑，是**点图标、点按钮**——这叫图形界面（GUI）。

而 CLI 是另一种方式：**你打字告诉电脑做什么，电脑打字回复你**。就这么简单。

**打个比方**：用 GUI 像在餐厅看图片菜单用手点；用 CLI 像直接跟厨师说"来一份番茄炒蛋，少放盐"。后者看着"高级"，其实只是换了种沟通方式——**本质上，CLI 就是你和电脑用打字聊天，跟你发微信没两样，只是聊天对象从朋友变成了电脑。**

为什么 AI 编程要用它？因为打字沟通**精确、快、可复制**——我给你的每条命令，你复制粘贴就能用，比截图教你点哪个按钮可靠得多。

你不需要记命令。**这个系列里所有命令，我都会给你能直接复制的整段，你粘进去回车就行。**

## 实操：10 分钟装好 Claude Code

理论铺垫完，开始动手。整个过程分四步，我按顺序给你。

<!-- IMAGE:04 type=infographic path=images/04-install-flow.png -->

![10分钟装好 Claude Code 四步](images/04-install-flow.png)

### 第一步：打开你的"命令行"

- **Windows**：按 `Win + R`，输入 `cmd`，回车。跳出一个黑色窗口——这就是命令行，别怕它。
- **Mac**：按 `Command + 空格`，输入 `终端` 或 `Terminal`，回车打开。

看到一个能打字的窗口就对了。

### 第二步：装好 Node.js（Claude Code 的运行底座）

Claude Code 需要 Node.js 才能跑。不用懂它是什么，照做即可。

最省心的办法——**把这句话直接发给任意一个 AI（豆包/通义/元宝都行）**，让它带你装：

```
帮我在这台电脑上安装 Node.js 最新稳定版，
我用的是 [Windows / Mac]（填你的系统），
请一步步告诉我怎么做，遇到报错我会把截图发给你。
```

装完后，在命令行输入这句验证：

```
node -v
```

只要返回一串版本号（如 `v20.11.0`），就说明装好了。

### 第三步：安装 Claude Code

命令行里粘进这一句，回车：

```
npm install -g @anthropic-ai/claude-code
```

等它跑完（可能要一两分钟）。装好后输入 `claude` 回车，能启动就成功。

### 第四步：接通国内可用的通道（LLM-Link）

直接用 Claude Code 会遇到网络和付费的坎。我们用 **LLM-Link 中转**绕过去——它帮你打通访问、还能按量付费省钱。

先去 LLM-Link 控制台**创建一个令牌**（选 `cc` 分组，日常推荐；高频可选 `cc-sale` 特价），复制那串以 `sk-` 开头的密钥。然后二选一接通：

**方式 A（推荐零基础）：用 CC-Switch 图形化工具**

CC-Switch 是个一键切换工具，点几下就好，不用碰配置文件：

1. 下载并打开 CC-Switch，分组选「Claude」
2. 供应商选「自定义配置」，名称填 `llm-link`，官网链接和请求地址都填 `https://www.llm-link.top`
3. API Key 粘贴你刚复制的令牌，点「添加」
4. 点「启用」，状态显示「使用中」即完成

![CC-Switch 配置 LLM-Link](images/06-ccswitch.png)

**方式 B：手动写配置文件**

愿意动手的话，更直接：

- Windows：按 `Win+R` 输入 `%userprofile%\.claude` 回车
- Mac/Linux：打开 `~/.claude` 目录

在里面新建（或编辑）`settings.json`，写入：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://www.llm-link.top",
    "ANTHROPIC_AUTH_TOKEN": "把你的-sk-令牌-粘到这里",
    "CLAUDE_CODE_ATTRIBUTION_HEADER": "0",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "CLAUDE_CODE_DISABLE_TERMINAL_TITLE": "1"
  }
}
```

把 `ANTHROPIC_AUTH_TOKEN` 换成你的令牌，保存即可。

两种方式选一个完成，就接通了。

## 避坑：装环境最常见的三个卡点

**坑 1：命令报错，看不懂。**
→ 别慌，**把报错整段截图或复制，发给豆包/通义**，说"我在装 Claude Code 报了这个错，怎么解决"。AI 比任何教程都懂你这台电脑的具体情况。

**坑 2：`npm` 或 `node` 提示"不是内部命令"。**
→ 说明 Node.js 没装好或没生效。重启命令行；还不行就回第二步，让 AI 重新带你装一遍。

**坑 3：设了中转还是连不上。**
→ 检查两点：环境变量名有没有打错、设完有没有**重开命令行**。90% 的连不上是这两个原因。

记住一个万能心法：**任何一步卡住，都可以把现象丢给 AI 问。** 你不是一个人在装。
