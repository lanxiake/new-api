## #cover：封面图

- 类型：AI生成（gpt-image-2）
- 尺寸：1536x1024
- 完整提示词：

```
彩色卡通漫画插画风格,横版构图,手绘质感,温暖友好,像绘本/漫画。

主题：一个普通人像产品经理一样,检查并指挥 AI 机器人干活,表达"人是负责验收和纠错的甲方"。

画面构成：
- 左侧：一个 Q 萌卡通小人,戴着小眼镜或拿着一块写字夹板(像产品经理在验收),表情认真又友善,手指着屏幕
- 中间：一个憨态可掬的卡通 AI 机器人,挠着头、额头冒一滴小汗,一副"哎呀我又写错了"的可爱表情
- 右侧：一块屏幕,上面一半打着绿色对勾、一半有个小红叉,表示"有的对有的错,需要人来把关"
- 周围点缀手绘箭头、对话气泡
- 最右侧留白浅暖色,用于叠加标题

视觉焦点：小人"验收把关" + 机器人"知错"的互动,要有幽默感

配色方案：
- 暖色调为主,明快活泼
- 橙色 #ff6b35 强调,深蓝 #1a3a5c 辅助

风格要求：
- 手绘卡通漫画质感,线条有手绘味
- 人物和机器人 Q 萌、有表情、有动作
- 温暖、幽默、有人情味

不要出现：
- 任何中文或英文文字
- 真实照片级人脸
- 冷硬扁平矢量图标风
- 3D 渲染、霓虹光效

输出：PNG,高清。
```

## #concept：AI 为什么会自信犯错（概念图）

- 类型：AI生成（gpt-image-2）
- 尺寸：1024x1024
- 完整提示词：

```
彩色卡通漫画信息图,手绘质感,像老师在白纸上画图讲解。

要表达的核心观点：AI 是在"接龙"猜下一个最像的词,所以它给的是"最像答案的东西",不一定正确,而且它从不说"我不确定"。

画面构成：
- 一个憨萌的卡通 AI 机器人站在中间,正在一节节地拼接"词语积木"连成一句话(像搭积木/接龙),每块积木上是抽象符号不写字
- 机器人头顶一个大大的、自信满满的对话气泡,里面打着一个看似肯定的对勾,但对勾旁边藏着一个小问号(暗示"看起来对,其实未必")
- 旁边一个卡通小人歪着头、一脸将信将疑地打量
- 用手绘箭头表示"一个词接一个词"的接龙过程

风格要求：
- 手绘卡通漫画质感,温暖幽默
- 机器人表情自信可爱,小人表情怀疑
- 手绘箭头、积木、对话气泡点缀

配色：暖色调为主,橙色 #ff6b35 强调,深蓝 #1a3a5c 辅助

不要：任何中英文文字、冷硬扁平矢量、3D 效果、真实照片人脸。

输出：PNG,高清。
```
