## 理论：API 是什么

**API = 餐厅里的服务员。**

你（你的程序）坐在餐桌前，厨房（第三方服务）里有你想要的东西，但你不能直接进厨房。

服务员（API）帮你传话：你告诉服务员"我要一份宫保鸡丁"，服务员把你的需求带进厨房，再把做好的菜端出来给你。

你不需要知道厨房怎么工作，你只需要懂得怎么跟服务员说话——这就是 API 调用。

<!-- IMAGE:01 type=cover path=images/01-cover.png -->

**API 调用的三要素：**

| 要素 | 含义 | 例子 |
|------|------|------|
| URL | 去哪家"餐厅" | `api.exchangerate.host/live` |
| 参数 | 你的"点单" | `?base=USD&symbols=CNY` |
| API Key | 你的"会员卡" | `?access_key=abc123` |

大多数 API 都要注册账号拿 Key，这样服务方知道是谁在调用、控制使用量。

## 理论：HTTP 请求——程序和 API 的通信方式

程序调用 API，本质是发一个 HTTP 请求，就像浏览器打开网页一样。

最常用的两种：
- **GET**：取数据（"查询今天的汇率"）
- **POST**：发数据（"帮我发送一条通知"）

API 返回的数据通常是 **JSON 格式**，Python 可以直接解析。

## 实操：给记账工具接入汇率 API

我们用 `exchangerate-api.com`——有免费套餐（每月 1500 次），不需要信用卡。

### 第一步：注册并拿到 API Key

1. 打开 `exchangerate-api.com`
2. 注册免费账号
3. 登录后在 Dashboard 看到你的 API Key，类似 `a1b2c3d4e5f6...`

### 第二步：让 AI 帮你接入

把 API 文档的关键信息告诉 AI：

```
我要给 Flask 记账工具接入汇率 API，使用 exchangerate-api.com。

API 调用方式（GET 请求）：
URL: https://v6.exchangeapi.com/v6/{YOUR_API_KEY}/pair/USD/CNY

返回的 JSON 格式：
{
  "conversion_rate": 7.23
}

请帮我：
1. 在记账工具里加一个"汇率查询"功能
2. 用户可以在记账时选择"外币"，输入金额和币种（如 USD 100）
3. 程序自动调用 API 换算成人民币后存入数据库
4. 把 API Key 存在环境变量 EXCHANGE_API_KEY 里，不要硬编码

我的 API Key 是：[把你的 key 粘贴这里]
```

### 第三步：在本地测试

```bash
# 设置环境变量后运行
EXCHANGE_API_KEY=你的key python accounting.py
```

试一下：录入一笔 100 美元的消费，看看程序能不能自动换算成人民币。

<!-- IMAGE:03 type=screenshot path=images/03-api-working.png -->

### 第四步：部署到线上

在 Railway 控制台的 Variables 里加一个环境变量：
- Name: `EXCHANGE_API_KEY`
- Value: 你的 API Key

然后：
```bash
git add .
git commit -m "feat: 接入汇率API，支持多币种记账"
git push
```

## 进阶：怎么找到你需要的任何 API

你想要的功能，99% 都有现成的 API：

| 你想要 | 搜什么 | 免费推荐 |
|--------|--------|---------|
| 汇率换算 | exchange rate API | exchangerate-api.com |
| 天气查询 | weather API free | OpenWeatherMap |
| 地图/地址 | geocoding API | OpenStreetMap Nominatim |
| 发送短信 | SMS API | Twilio（有免费额度） |
| 发送邮件 | email API | Resend / SendGrid |
| AI 对话 | LLM API | LLM-Link（聚合多家模型） |

找到 API 后，告诉 AI：

```
我找到了一个 [API名称] 的文档，地址是 [文档URL]。
请帮我分析：
1. 这个 API 怎么鉴权（API Key 放在哪里）？
2. 我想实现 [具体功能] 需要调用哪个接口？
3. 帮我写一段 Python 代码测试这个接口是否可用。
```

AI 能读 API 文档，你不需要自己读——这是 AI 辅助编程最高效的场景之一。

## 避坑：API 调用最常见的三个问题

**问题 1：`401 Unauthorized` 或 `403 Forbidden`**

鉴权失败——通常是 Key 写错了，或者放的位置不对（有的放 Header，有的放 URL 参数）。

```
我调用 [API名称] 时返回 401 错误，我的代码如下：
[粘贴代码]
API 文档说鉴权方式是：[粘贴文档相关段落]
请帮我找出哪里错了。
```

**问题 2：免费额度用完了**

大多数 API 有免费额度限制。超出后要么报错，要么收费。

应对策略：
- 加缓存：相同查询结果缓存 1 小时，减少调用次数
- 用环境变量控制：调试时用本地假数据，生产环境才调 API

```
我的汇率 API 每月只有 1500 次免费额度，我的应用访问量越来越多，快超了。
请帮我给 API 调用加一个缓存层（用 Python 内存缓存，有效期 1 小时）。
```

**问题 3：API 返回了数据，但解析出错**

JSON 结构和你预期的不一样——先打印原始返回，再让 AI 帮你解析。

```python
# 在代码里加这一行临时调试
print(response.json())
```

把打印出的内容发给 AI，让它帮你找到正确的字段路径。
