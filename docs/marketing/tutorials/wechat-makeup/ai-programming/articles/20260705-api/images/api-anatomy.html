API 调用解剖
一个 API 请求由三部分组成
完整请求 URL
https://v6.exchangeapi.com/v6/YOUR_API_KEY/pair/USD/CNY
1
Base URL（去哪）
v6.exchangeapi.com
API 服务的地址，就像餐厅的门牌号
2
API Key（你是谁）
YOUR_API_KEY
注册后获得的密钥，让服务方认识你、计费
3
参数（要什么）
/pair/USD/CNY
你的"点单"：把美元换算成人民币
API 返回的 JSON 数据
{
  "result": "success",
  "base_code": "USD",
  "target_code": "CNY",
  "conversion_rate": 7.2341
}
