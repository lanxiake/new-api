三层架构·寄快递类比
一次点击背后，是前端 → 后端 → 数据库的三层接力
🖥️
前端
Vue · HTML · CSS
用户看到的所有界面
按钮、表单、图片、动画
收集用户输入，展示结果
不存数据，不做判断
🏪 类比：购物网站的网页
展示商品、让你填地址，但不知道仓库有多少货
请求
⇄
响应
⚙️
后端
Python · Flask · Node
处理所有业务逻辑
验证账号、计算金额、权限判断
连接数据库读写数据
调用第三方服务（支付/短信）
🏢 类比：快递调度中心
决定从哪发货、走哪条路线、通知哪个快递员
查询
⇄
数据
🗄️
数据库
MySQL · PostgreSQL
永久保存所有数据
用户信息、交易记录、设置
程序关闭数据不消失
支持查询、统计、过滤
📒 类比：仓库台账本
每笔单子、每个地址、每个包裹状态全记在上面
前端发请求 → 后端处理 → 数据库存取 → 后端返回 → 前端展示
