## 功能目标：自然语言记账

现在的记账工具，你要手动填写：金额、类型、备注。

升级后，你只需要说一句话：

> "刚才在沃尔玛买菜花了 142 块"

程序自动解析出：
- 金额：142
- 类型：支出
- 备注：沃尔玛买菜
- 日期：今天

这就是 NLP（自然语言处理）——用 AI 读懂人话。

## 实操：接入 AI 实现自然语言输入

### 第一步：在 LLM-Link 注册并拿到 API Key

LLM-Link 是 AI 模型的聚合平台，一个 Key 可以调用 GPT、Claude、Gemini 等几十个模型。

1. 打开 `llm-link.top`，注册账号
2. 创建一个 API Key
3. 给账户充值（新用户通常有免费额度）

### 第二步：让 AI 写解析代码

```
我要给 Flask 记账工具加一个自然语言输入功能，调用 LLM API 解析用户输入。

需求：
1. 用户在输入框里输入自然语言，比如"刚才吃饭花了58块"
2. 程序把这句话发给 AI，让 AI 返回结构化 JSON：
   {
     "amount": 58,
     "type": "支出",
     "note": "吃饭",
     "date": "2025-01-06"
   }
3. 把解析结果自动填入表单，用户确认后存数据库

技术要求：
- 使用 OpenAI SDK，base_url 改为 https://api.llm-link.top/v1
- 模型用 gpt-4o-mini（便宜、够用）
- API Key 存环境变量 LLM_API_KEY
- 如果 AI 解析失败，返回错误提示让用户手动填写

System prompt（让 AI 专注解析）：
你是一个记账助手。用户输入一句自然语言，你需要提取：amount（数字）、type（"收入"或"支出"）、note（简短备注）、date（YYYY-MM-DD，没说明就用今天）。只返回 JSON，不要任何解释。
```

### 第三步：在本地测试

```bash
LLM_API_KEY=你的key python accounting.py
```

在输入框输入"上周收到客户转账三千二"，看看解析结果是否正确。

## 成本控制：算清 AI 调用的账

很多人对"调用 AI API"有误解，要么觉得很贵不敢用，要么乱用导致账单超预期。

让我们把账算清楚。

### Token 是什么

AI 按 **Token** 计费，大约 1 个 Token ≈ 1.5 个汉字 或 0.75 个英文单词。

一次自然语言记账调用：
- 输入：System prompt（约 100 token）+ 用户一句话（约 20 token）= 120 token
- 输出：JSON 结果（约 50 token）= 50 token

**合计：约 170 token**

### 不同模型的成本对比

<!-- IMAGE:03 type=infographic path=images/03-cost-table.png -->

用 `gpt-4o-mini` 做记账解析：

- 每次调用成本：约 $0.000034（不到一厘钱）
- 每天记 10 笔账：$0.00034
- 每月：约 $0.01（一分钱不到）

**结论：自然语言记账几乎是免费的。**

只有当你的应用有大量用户（每天几千次调用），才需要认真考虑成本优化。

### 用 LLM-Link 管控成本的三个方法

**方法 1：按任务选模型**

| 任务 | 推荐模型 | 理由 |
|------|----------|------|
| 简单解析、分类 | gpt-4o-mini / gemini-flash | 够用，便宜 10 倍 |
| 复杂推理、代码生成 | gpt-4o / claude-3-5-sonnet | 质量更好 |
| 长文档处理 | gemini-1.5-pro | 超长上下文 |

**方法 2：设置用量上限**

LLM-Link 控制台可以给每个 Key 设置月度用量上限，超了自动停止，不会有意外账单。

**方法 3：加缓存**

相同输入 → 相同输出。如果用户重复输入相似的话（"吃饭花了50"），可以缓存结果，减少 API 调用。
