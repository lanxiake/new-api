终端报错不要慌
把报错丢给 AI，它比教程更懂你的电脑
⚠️
坑 1：python 不认识
'python' 不是内部或外部命令，
也不是可运行的程序
原因：Python 未安装或未加入 PATH
解法：把报错发给 AI，说"我用的是 Windows，帮我解决"
⚠️
坑 2：找不到路径
系统找不到指定的路径。
原因：中文系统桌面叫"桌面"非"Desktop"
解法：改用 cd 桌面
⚠️
坑 3：中文乱码
UnicodeEncodeError: 'gbk' codec
can't encode character...
原因：编码不一致，中文 Windows 常见
解法：文件首行加 # -*- coding: utf-8 -*-
万能原则：复制报错 → 发给 AI，告诉它"我在跑 Python，出现了这个错"
