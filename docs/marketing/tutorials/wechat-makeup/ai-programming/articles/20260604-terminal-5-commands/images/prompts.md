# 第05篇配图提示词

## #cover

封面图，科技风格，深蓝黑渐变背景。画面中央是一个圆角黑色终端窗口，窗口里显示绿色文字光标在闪烁，旁边有5个发光的命令标签浮动：pwd、ls、cd、mkdir、python。左侧站着一个卡通小人，表情从紧张变成自信的微笑，手指向终端窗口。右上角有白色中文标题"终端不可怕"，副标题"你只需要会这5条命令"。整体配色：深蓝#0a1628、亮青#00d4ff、绿色代码色#39ff14。无Emoji，无乱码，清晰简体中文。

## #terminal-vs-gui

信息图，白底或浅灰底，分为左右两栏对比。左栏标题"图形界面（点击）"，画面是鼠标点击图标的示意图，旁边写"只能做菜单上有的"。右栏标题"终端（打字）"，画面是键盘打字的示意图，旁边写"直接和电脑说话"。中间用双向箭头连接。底部一行大字：终端 = 用打字和电脑聊天。配色明快，蓝白为主，line icon风格，无Emoji，清晰简体中文。

## #five-commands

信息图，深蓝黑科技底色，竖向排列5个命令卡片，每张卡片左侧是命令名（绿色代码字体），右侧是中文说明和生活类比图标。从上到下：pwd（我在哪？/手机定位图标）、ls（看文件夹内容/文件夹图标）、cd（进入文件夹/箭头进入图标）、mkdir（新建文件夹/加号图标）、python（运行程序/播放按钮图标）。顶部标题"5条命令，够用一辈子"。霓虹描边玻璃质感，无Emoji，无乱码，清晰简体中文。

## #cheatsheet

速查卡片风格，白底，圆角矩形边框，内部是整洁的表格：6行3列（命令/作用/类比），表头深蓝底白字，交替行浅蓝/白色。底部写"可截图保存"。字体清晰，无Emoji，无乱码，清晰简体中文。

## #error-guide

信息图，三个并排卡片，每张卡片顶部是一个红色警告图标，中间是报错描述（简短），底部是绿色对勾+解决方案。卡片1：python不是命令；卡片2：找不到路径；卡片3：乱码。底部大字金句："报错 = 电脑在告诉你一件事，不是你搞坏了什么"。配色：卡片白底，警告红，解决方案绿，背景浅灰。无Emoji，清晰简体中文。
