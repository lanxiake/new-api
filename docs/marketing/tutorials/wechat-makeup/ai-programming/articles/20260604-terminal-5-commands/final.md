## 理论：终端是什么？重新认识那个黑色窗口

在动手之前，我要先帮你彻底祛魅——**不是因为要讲大道理，是因为你对它的误解，才是让你怕它的真正原因。**

<!-- IMAGE:02 type=infographic path=images/02-terminal-vs-gui.png -->

你平时用电脑，是这样的：**看图标 → 移鼠标 → 点击 → 看结果**。

这叫图形界面（GUI）。它的好处是直观，坏处是你只能做软件"允许你点的"那些操作。

而终端，是另一种沟通方式：**你打字 → 电脑执行 → 打字回复你**。

打个比方：

> 用图形界面，就像在餐厅用平板点餐——菜单上有什么，你才能点什么；
>
> 用终端，就像直接跟厨师说话——"来一份番茄炒蛋，少放盐，多放葱花，火候要大"。灵活得多，但你得用语言说清楚。

**终端的本质，就是你用打字和电脑聊天。和你在微信发消息没有本质区别，只是聊天对象从朋友变成了电脑。**

那它为什么看起来那么可怕？两个原因：

第一，**黑底白字的视觉风格**。设计上没有图标、没有颜色引导，人天生对陌生的黑暗感到警觉。但这只是视觉，不是危险。

第二，**教程总是一口气教几十条命令**。信息量太大造成恐惧——就像有人一次性给你背一百个单词，你不是学不会，是被吓跑了。

今天我们只学 5 条。而且我会告诉你，这 5 条之外，其他你全不用记——需要的时候问 AI 就行。

## 5 条命令，现在就学会

我帮你把日常操作浓缩到最小集合。这 5 条命令，覆盖你在 AI 编程过程中**90% 的场景**。

<!-- IMAGE:03 type=infographic path=images/03-five-commands.png -->

### 第 1 条：`pwd` — 我在哪里？

```bash
pwd
```

**你在文件系统里的当前位置**。就像打开手机地图，先看"我的位置"。

运行后会输出类似这样的路径：

```
/Users/yourname/Documents
```

或者在 Windows 上：

```
C:\Users\yourname\Documents
```

**记住**：进入终端后，第一件事是 `pwd` 确认自己在哪，就像导航前先定位。

---

### 第 2 条：`ls` — 这里有什么？（Windows 用 `dir`）

```bash
ls          # Mac / Linux
dir         # Windows
```

**列出当前文件夹里的所有文件和子文件夹**。就像打开文件夹看里面有什么，只是用打字代替了双击。

---

### 第 3 条：`cd` — 去某个文件夹

```bash
cd 文件夹名称
```

**进入某个文件夹**。`cd` 是 "change directory" 的缩写——换目录。

几个常用变体：

```bash
cd Desktop          # 进入桌面（Mac/Linux）
cd ..               # 返回上一级（两个点代表"上级"）
cd ~                # 回到你的主目录（家目录）
```

**类比**：`cd` 就是在文件夹里"双击进去"——只不过你是用打字完成的。`cd ..` 就是点左上角那个"返回"箭头。

---

### 第 4 条：`mkdir` — 新建文件夹

```bash
mkdir 文件夹名称
```

**创建一个新文件夹**。就是图形界面里"右键 → 新建文件夹"的打字版。

例如：

```bash
mkdir my-project
```

---

### 第 5 条：`python` / `node` — 运行程序

```bash
python 文件名.py        # 运行 Python 程序
node 文件名.js          # 运行 JavaScript 程序
```

**执行你写好的程序文件**。这是 AI 帮你生成代码之后，你真正让它"跑起来"的那一步。

---

### 速查卡片（可截图保存）

| 命令 | 作用 | 类比 |
|------|------|------|
| `pwd` | 查看当前位置 | 手机地图"我的位置" |
| `ls` / `dir` | 查看文件夹内容 | 打开文件夹看里面 |
| `cd 文件夹名` | 进入文件夹 | 双击文件夹 |
| `cd ..` | 返回上一级 | 点"返回"箭头 |
| `mkdir 名称` | 新建文件夹 | 右键→新建文件夹 |
| `python 文件.py` | 运行 Python 程序 | 双击程序图标运行 |

## 实操：用这 5 条命令跑出第一个程序

光看不够，现在我们用这 5 条命令完成一个真实任务。

**目标**：建好项目文件夹，让 AI 写一个小程序，然后你来跑它。

**预计时间**：5-15 分钟

---

### 第一步：打开终端

- **Windows**：按 `Win + R`，输入 `cmd`，回车
- **Mac**：按 `Command + 空格`，输入 `Terminal`，回车

看到那个闪烁的光标就对了。

---

### 第二步：建好你的项目文件夹

把这几条命令**逐行复制粘贴**，每粘一条就回车：

```bash
cd Desktop
mkdir ai-practice
cd ai-practice
pwd
```

最后那条 `pwd` 会打印出你的当前位置，确认你已经进入了刚刚新建的 `ai-practice` 文件夹。

---

### 第三步：启动 Claude Code，让它给你写程序

好了，到了真正用 Claude Code 的时刻——**确认你在项目文件夹里**（`pwd` 看一眼），然后输入：

```bash
claude
```

回车。Claude Code 启动后是这样的：一个交互式的对话界面，右上角显示当前模型，下方有一个可以打字的输入框。

<!-- IMAGE:07 type=screenshot path=images/07-claude-launch.png -->

进来之后，几个你马上会用到的操作：

| 操作 | 命令 / 快捷键 | 说明 |
|------|--------------|------|
| 发送消息 | 输入后按 `Enter` | 普通消息，AI 直接回复 |
| 换行不发送 | `Shift + Enter` | 写多行提示词时用 |
| 退出 Claude Code | 输入 `/exit` 或按 `Ctrl + C` | 回到普通终端 |
| 查看帮助 | 输入 `/help` | 列出所有可用命令 |
| 清空对话 | 输入 `/clear` | 开始新的对话，不影响文件 |

> **一个重要习惯**：每次用 Claude Code 前，先 `cd` 进你的项目文件夹再启动。它会以当前目录为"工作范围"，这样它帮你建文件、改代码都在正确位置。

启动后，把这段提示词直接复制粘贴进去：

```
请帮我写一个 Python 程序，功能如下：

1. 程序启动后，问我"你叫什么名字？"
2. 我输入名字后，程序打印一句话：
   "[我的名字]，你好！今天是 [今天的日期]，AI 编程你已经入门了，加油！"
3. 代码保存为 hello.py，请直接给我完整代码，不需要解释。
```

AI 会给你一段完整的 Python 代码。把它**完整复制**，在 `ai-practice` 文件夹里新建一个文件，命名为 `hello.py`，把代码粘进去保存。

> 怎么新建文件？最简单的方式：用记事本（Windows）或文本编辑器（Mac）新建，保存时把文件名改成 `hello.py`，注意扩展名是 `.py` 不是 `.txt`。

---

### 第四步：跑起来

回到终端，确认你还在 `ai-practice` 文件夹里（`pwd` 确认一下），然后：

```bash
python hello.py
```

回车。程序会问你名字，输入自己的名字，再回车——

<!-- IMAGE:05 type=screenshot path=images/05-result.png -->

**如果你看到一句带着你名字的话出现在屏幕上——你刚刚跑通了第一个 AI 帮你写的程序。**

这个程序是你用 5 条命令和一段提示词召唤出来的。没有学任何语法，没有背任何 API——你只是说清楚了你想要什么。

## 避坑：终端报错时不要慌

说完成果，必须说避坑。终端报错是**一定会发生的常态**，不是你的问题，不要慌。

<!-- IMAGE:06 type=infographic path=images/06-error-guide.png -->

**坑 1：`python` 提示"不是内部或外部命令"（Windows）**

→ Python 没有正确安装，或者安装时没勾选"Add to PATH"。解决方案：把这句报错截图，发给 AI 说"我在运行 python 时报了这个错，我用的是 Windows，帮我解决"。

**坑 2：`cd Desktop` 进不去，说"找不到路径"**

→ 可能你的系统语言是中文，桌面文件夹叫"桌面"不叫"Desktop"。

```bash
cd 桌面          # 中文 Windows 试这个
```

**坑 3：程序跑了但乱码**

→ 编码问题，中文环境常见。在 `hello.py` 第一行加上这句再试：

```python
# -*- coding: utf-8 -*-
```

**万能原则**：终端里出现红色文字或"Error"，**完整复制那段报错，粘给 AI**，说"我在用终端跑 Python 程序，出现了这个报错，帮我解决"。AI 比任何教程都懂你这台电脑的具体情况。

报错不是失败，报错是电脑在告诉你"有一件事没做对"——而且它还贴心地告诉了你是什么事。把这句话记住，以后你就不怕报错了。
