## 理论：为什么"加个界面"涉及前后端两部分

加界面不是"给程序画个好看的皮"这么简单。

<!-- IMAGE:01 type=cover path=images/01-cover.png -->

命令行工具的工作方式是这样的：
```
你输入 → 程序处理 → 打印文字 → 你再输入
```

网页工具的工作方式变成了：
```
浏览器显示界面 → 你点击/输入 → 发请求给后端 → 后端处理 → 返回结果 → 浏览器更新界面
```

**多出来的这一层就是"前后端分工"：**
- **前端**（HTML + JavaScript）：负责在浏览器里显示界面、响应你的操作
- **后端**（Python + Flask）：负责处理逻辑、读写数据，和之前的命令行逻辑一样

你之前的 `accounting.py` 就是后端逻辑——它处理账单的核心代码不需要大改，只需要：
1. 给它套上一个"Web 服务"的壳（Flask）
2. 写一套网页界面（HTML + CSS + JS）

## 实操：升级到网页版记账工具

### 第一步：让 AI 添加 Flask 后端

在上篇的 `accounting-tool` 目录里，启动 Claude Code，粘入这段提示词：

```
现在我要把命令行记账工具升级为网页版。

请帮我做以下修改：

1. 安装 Flask（在终端运行 pip install flask）

2. 修改 accounting.py：
   - 把现有的记账逻辑（读写 data.json）保留，不要动
   - 用 Flask 包装成 Web API，提供以下接口：
     - GET  /api/records    → 返回所有账单记录（JSON格式）
     - POST /api/records    → 新增一条记录，接收 {type, amount, note}
     - GET  /api/balance    → 返回当前余额
   - 启动后在 http://localhost:5000 提供服务

3. 新建 index.html：
   - 简洁的网页界面，包含：
     - 顶部：显示当前余额（收入/支出/净余额）
     - 中部：表单，填写类型/金额/备注，点"记账"按钮提交
     - 下部：按时间倒序显示所有账单列表
   - 样式要好看，不要单调的黑白，可以用卡片式布局
   - 使用原生 JavaScript，不引入第三方框架

4. 启动命令：python accounting.py
   启动后在终端显示：
   "记账工具已启动：http://localhost:5000"
```

### 第二步：安装依赖，运行

AI 改完之后，先安装 Flask：

```bash
pip install flask
```

然后运行：

```bash
python accounting.py
```

看到 `记账工具已启动：http://localhost:5000` 后，打开浏览器，访问 `http://localhost:5000`。

<!-- IMAGE:03 type=screenshot path=images/03-web-ui.png -->

### 第三步：在手机上访问

手机和电脑在同一个 WiFi 下，就能用手机浏览器访问你电脑上的程序。

先查电脑的 IP 地址：

- **Windows**：打开终端，输入 `ipconfig`，找"IPv4 地址"那行（通常是 `192.168.x.x`）
- **Mac**：打开终端，输入 `ifconfig | grep inet`，找以 `192.168.` 开头的那个

然后修改启动代码，让它接受局域网访问：

```
请在 Flask 启动代码里加一个参数：
app.run(host='0.0.0.0', port=5000, debug=False)

这样局域网内的其他设备就能通过 http://你电脑IP:5000 访问了
```

手机浏览器里输入 `http://你的IP:5000`，就能用了。

你现在有了什么：

## 避坑：网页版常见的三个问题

**问题 1：浏览器打开是空白页或报错**

通常是 Flask 没启动或端口被占用。检查终端里有没有报错，看 `http://localhost:5000` 前有没有 `* Running on` 那行输出。如果端口 5000 被占用，换一个端口：

```
请把端口从 5000 改为 5001
```

**问题 2：手机访问不了**

最常见原因：Windows 防火墙拦截了 5000 端口。把这个报给 AI：

```
我在 Windows 上运行 Flask，电脑浏览器可以访问 http://localhost:5000，
但手机在同一 WiFi 下访问 http://192.168.x.x:5000 打不开。
请告诉我怎么在 Windows 防火墙里放行 5000 端口。
```

**问题 3：提交记账后界面没更新**

JavaScript 发送了请求，但没有刷新显示的数据。让 AI 修：

```
提交记账表单后，账单列表没有自动更新，需要手动刷新页面才能看到新记录。
请修改前端代码：提交成功后自动重新加载账单列表，不需要整页刷新。
```

## 本篇小结

三句话，可以截图保存：

1. **命令行 → 网页 = 加了一层前端界面**，后端逻辑基本不变，多了 Flask 和 HTML
2. **前端（HTML+JS）负责界面，后端（Python+Flask）负责数据**——这是所有网页应用的基础结构
3. **局域网访问 = 手机电脑同 WiFi + Flask 绑定 0.0.0.0**，不需要任何服务器
