怎么读报错信息
不需要全看懂——只找这三个位置就够了
Traceback (most recent call last):
  File "accounting.py", line 23, in load_data
    return json.load(f)
  File "/usr/lib/python3.11/json/__init__.py", line 293, in load
    return loads(fp.read(), ...)
json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)
1
最后一行 → 错误类型 + 原因（最重要）
JSONDecodeError 是错误类型，Expecting value: line 1 column 1 是原因——说明文件第1行是空的，没有内容可以解析
2
最后一个 File → 你的代码出问题的位置
File "accounting.py", line 23 — 是你的程序文件，第23行，函数 load_data 里面出了问题
3
中间那堆 → 调用路径（一般不用看）
显示程序是怎么一步步走到报错那行的。大多数情况下不需要管这部分，看最后两项就够了
把报错最后一行 + 你做了什么操作，一起发给 AI — 这是修报错最高效的方式
