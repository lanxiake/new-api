报错四大类型一览
认出类型，对症下药——90% 的情况 AI 都能帮你修
⚙️
环境
错误
ModuleNotFoundError: No module named 'flask'
command not found: python
Python 没装好，或缺少依赖包。程序还没运行就出错了。
给 AI：报错 + 你的系统（Win/Mac）
📝
语法
错误
SyntaxError: invalid syntax
IndentationError: unexpected indent
代码格式写错了（少括号、缩进错误等）。AI 写的代码不该有，直接给 AI 修。
给 AI：完整报错信息
💥
运行时
崩溃
KeyError: 'amount'
FileNotFoundError: 'data.json'
TypeError: can't add str + int
程序跑起来了，但执行到某步出错了。最常见的类型。
给 AI：报错 + 做了什么操作 + 期望结果
🔍
逻辑
错误
（不报错，但结果不对）
余额算错了 / 排序反了 / 数据没保存
最难发现的一类——程序没崩溃，但行为不符合预期。需要你主动测试发现。
给 AI：期望结果 vs 实际结果的对比
