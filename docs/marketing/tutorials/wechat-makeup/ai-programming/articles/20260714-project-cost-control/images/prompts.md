# 图片提示词记录

> 文章：第14篇 项目实战 + 成本控制——做一个副业级工具，并算清每一笔账
> 视觉风格：彩色卡通漫画风（对标公众号《风声的AI编程》），手绘质感、Q萌小人、温暖幽默
> 统一配色：暖色为主；橙色 #ff6b35 强调；深蓝 #1a3a5c 辅助
> 生成方式：封面/原理/对照表图用 gpt-image-2（经 LLM-Link）；操作截图用 CloakBrowser 真实截取

## #cover：封面图（01-cover.png）

- 类型：AI生成（gpt-image-2）
- 用途：公众号封面 + 文章顶图
- 尺寸：1536x1024
- 标题文字：右侧留白区后期叠加，不让 AI 写中文
- 完整提示词：

```
彩色卡通漫画插画风格，横版构图，手绘质感，温暖友好，像绘本/漫画。

主题：一个普通人用 AI 做出了自己的副业小工具，并轻松地算清了账，氛围满足、有成就感。

画面构成：
- 左侧：一个 Q 萌卡通小人，面带满足微笑，一手指着笔记本屏幕上一个可爱的小网页工具（有输入框和几张文案卡片），另一手拿着一张写满数字的小账单纸条
- 中间偏右：一个憨态可掬的卡通 AI 机器人（圆润可爱），旁边漂浮着一杆卡通小天平/算盘，一头是大金币、一头是小金币，暗示"花得明白、算得清账"
- 周围飘着手绘小装饰：金币、对话气泡、爱心点赞、上升的小箭头
- 右侧 1/4 区域：留白或浅暖色背景，用于后期叠加标题

视觉焦点：小人 + 工具 + 账单的"做成了且算清了"满足感

配色：暖色调为主，橙色 #ff6b35 强调（机器人配件、金币、箭头），深蓝 #1a3a5c 辅助，柔和不刺眼

风格要求：手绘卡通漫画质感，线条有手绘味；人物和机器人 Q 萌有表情有动作；温暖、有人情味、略带幽默

不要出现：任何中文或英文文字、真实照片级人脸、冷硬扁平矢量风、3D渲染、赛博朋克霓虹

输出：PNG，高清。
```

## 02-cost-structure.png：原理图·"请不同档次的人"

- 类型：AI生成（gpt-image-2）
- 用途：讲清"模型选择 = 看活派人"
- 尺寸：1536x1024
- 完整提示词：

```
彩色卡通漫画信息图风格，横版，手绘质感，温暖幽默。

主题：用"请不同档次的人干活"类比"选不同价位的 AI 模型"。

画面分左右两组对比：
- 左组「跑腿小活·请便宜实习生」：一个 Q 萌的年轻卡通实习生小人，快步跑着送一张写文案的小纸条，旁边一个小钱袋（很小，几枚硬币），配一个轻松的笑脸。任务标签画成"写简单文案/分类"的可爱小图标。
- 右组「硬骨头·请资深专家」：一个戴眼镜、稍年长的卡通专家小人，认真对着一台复杂机器/一团缠绕的线缆（代表疑难问题），旁边一个大钱袋（鼓鼓的金币）。任务标签画成"重构项目/解疑难报错"的小图标。
- 中间用一杆卡通天平或一个"看活派人"的箭头连接两组，暗示"按任务难度选人/选模型"

配色：暖色为主，橙色 #ff6b35 强调钱袋与箭头，深蓝 #1a3a5c 辅助

风格：手绘卡通漫画，Q 萌有表情，对比清晰一眼看懂

不要出现：中文或英文文字（标签用图标表达，不写字）、真实人脸、冷硬扁平矢量、3D、霓虹

输出：PNG，高清。
```

## 04-cost-table.png：成本对照表可视化

- 类型：AI生成（gpt-image-2）或 设计工具排版
- 用途：把"模型选对了成本差几十倍"画成一眼看懂的对照
- 尺寸：1536x1024
- 完整提示词：

```
彩色卡通信息图风格，横版，手绘质感，干净清爽，像一张温暖的对照卡片。

主题：三种 AI 模型做同一件"写文案"任务的成本对照，强调"选对模型省几十倍钱"。

画面构成：三列卡通价签/钱袋对比，从左到右金额递增：
- 第1列「便宜快·首选」：一个很小的钱袋 + 一颗绿色的勾，旁边一个开心的 Q 萌小人竖大拇指
- 第2列「质量更高」：一个中等钱袋 + 一个中性表情
- 第3列「没必要用」：一个超大鼓胀的钱袋 + 一个吓一跳/捂钱包的卡通表情 + 一个红色叉
- 三列下方用从矮到高的卡通柱状条暗示成本差距悬殊（最后一根特别高）
- 顶部留白用于后期叠加"成本差几十倍"标题

配色：暖色为主，橙色 #ff6b35 强调，绿色勾/红色叉点缀，深蓝辅助

风格：手绘卡通，对比强烈、一眼看懂"差距悬殊"

不要出现：中文或英文文字（用图标/表情/柱高表达）、真实人脸、冷硬矢量、3D、霓虹

输出：PNG，高清。
```
