## #cover：封面图

- 类型：AI生成（gpt-image-2）
- 用途：公众号封面 + 文章顶图
- 尺寸：1536x1024
- 标题文字：右侧/上方留白区后期叠加（也可直接让 AI 写中文标题）
- 完整提示词：

```
温暖人文风格的扁平插画，横版构图，柔和手绘质感，情绪细腻，像绘本内页。

主题：一个"非常乖"的小孩，把真实的自己悄悄藏了起来。

画面构成：
- 画面中央：一个五六岁的小孩，端端正正坐着或站着，脸上挂着一个礼貌、乖巧、有点过度懂事的微笑，姿态拘谨、双手放得很规矩
- 在小孩身体的内部或身后，用半透明、柔和的方式透出"另一个他"——一个想伸手、想奔跑、想表达、色彩更鲜亮的小小身影，被一层灰蒙蒙的轮廓轻轻包裹住、压抑住
- 外在的"乖"用平淡的米灰/暖灰色调，内在被藏起来的"真实自我"用温暖明亮的珊瑚橙、嫩绿、暖黄
- 周围环境留白干净，可点缀一两个柔和的手绘装饰（飘落的纸片、一支没在画画的蜡笔）
- 右侧或上方留出约 1/3 的干净留白区，用于后期叠加中文标题

情绪基调：不恐怖、不煽情，而是一种让人心里轻轻一沉的温柔——"这个孩子太懂事了，懂事得让人心疼"

配色方案：
- 暖色系为主：米黄 #fff8f0、珊瑚橙 #f0875a、暖绿 #6bbf8a、奶油白
- 外在压抑感用低饱和暖灰
- 整体柔和不刺眼

风格要求：
- 扁平插画 + 手绘质感，线条柔软，有温度
- 人物有细腻的表情，能读出"乖的表面"和"被藏住的内心"两层
- 人文、温暖、有故事感，不要冷硬科技风

不要出现：
- 真实照片级人脸
- 冷硬的扁平矢量图标风、3D 渲染、赛博朋克、霓虹光效
- 深蓝黑底（本系列走暖色，不走科技风）

输出：PNG，高清。
```

## #mechanism：原理隐喻插画（压抑自我换安全）

- 类型：AI生成（gpt-image-2）
- 用途：插在"一个'太乖'的孩子，内心到底发生了什么"那节末尾，把"压抑自我换取安全"的心理机制变成一眼能懂的画面
- 尺寸：1024x1024
- 完整提示词：

```
温暖人文风格的扁平插画，方形构图，柔和手绘质感，用一个隐喻把心理机制画出来，不要任何文字。

要表达的核心机制：孩子为了换取"被爱、被认可"的安全感，主动把自己丰富、鲜活、各种形状的"真实自我"，硬塞进一个统一、规整、灰扑扑的"乖孩子模具"里。

画面隐喻（择优清晰呈现）：
- 左边：一个孩子手里捧着一团温暖明亮、形状自由、五彩斑斓的小光球或小生物（象征他真实的意愿和天性），它是活泼的、不规则的、会发光的
- 中间：一个灰色的、规规矩矩的方形模具/盒子（象征"乖"的标准模板），开着口
- 右边/结果：孩子把那团彩色的自己塞进灰盒子后，盒子表面浮现出一个标准的、礼貌的、统一的微笑符号（用图形而非文字），而盒子缝隙里还漏出一点点没被完全塞进去的暖色微光——暗示真实自我没有消失，只是被压住了
- 孩子的表情：努力、乖顺，又带着一丝不易察觉的失落

情绪基调：温柔的惋惜，不批判家长，让人看懂"代价"

配色方案：
- 真实自我 = 温暖明亮：珊瑚橙 #f0875a、暖黄、嫩绿 #6bbf8a
- 模具/乖的外壳 = 低饱和暖灰
- 背景奶油白 #fffbf0，干净

风格要求：
- 扁平插画 + 手绘质感，柔软有温度
- 隐喻清晰，普通家长一眼能看懂"鲜活的自己被塞进灰模具"
- 人文温暖，不要冷硬、不要恐怖

不要出现：
- 真实照片级人脸
- 冷硬扁平矢量图标风、3D 渲染、霓虹光效

输出：PNG，高清。
```
