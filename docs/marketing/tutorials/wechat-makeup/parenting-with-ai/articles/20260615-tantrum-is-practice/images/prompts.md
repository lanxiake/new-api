## #cover：封面图

- 类型：AI生成（gpt-image-2）
- 用途：公众号封面 + 文章顶图
- 尺寸：1536x1024
- 标题文字：右侧/上方留白区后期叠加（也可直接让 AI 写中文标题）
- 完整提示词：

```
温暖人文风格的扁平插画，横版构图，柔和手绘质感，情绪细腻，像绘本内页。

主题：一个小孩正在发脾气，而旁边的大人没有慌乱，而是平静地蹲下来陪着他——传递"情绪是被允许的，有人陪着你"的温暖感。

画面构成：
- 画面中央偏左：一个四五岁的小孩，坐在地上或蹲着，表情委屈、眼眶红红的，身体语言是"我很难受"，但不是愤怒或暴力，是那种憋着的委屈
- 小孩身边：一个大人（家长）蹲下来，身体姿态是放低的、靠近的，表情平静而温柔，没有焦虑，没有评判，就是陪着
- 两人之间有一种无形的连接感——可以用柔和的光晕、暖色的氛围来表达
- 周围环境简洁，可以是家里的地板或公园的草地，点缀一两个手绘装饰（飘落的叶子、一个小玩具）
- 右侧或上方留出约 1/3 的干净留白区，用于后期叠加中文标题

情绪基调：温暖、被接纳、"情绪是可以经历的"——不是压制，不是解决，是陪伴

配色方案：
- 暖色系为主：米黄 #fff8f0、珊瑚橙 #f0875a、暖绿 #6bbf8a、奶油白
- 小孩的委屈用低饱和的蓝灰点缀（眼眶、表情），与整体暖色形成轻微对比
- 整体柔和不刺眼

风格要求：
- 扁平插画 + 手绘质感，线条柔软，有温度
- 人物有细腻的表情，能读出"委屈的孩子 + 平静陪伴的大人"两种情绪
- 人文、温暖、有故事感，不要冷硬科技风

不要出现：
- 真实照片级人脸
- 冷硬的扁平矢量图标风、3D 渲染、赛博朋克、霓虹光效
- 深蓝黑底

输出：PNG，高清。
```

## #mechanism：原理隐喻插画（情绪被命名后自然平息）

- 类型：AI生成（gpt-image-2）
- 用途：插在"说出感受，为什么比停止哭泣更重要"那节末尾，把"命名情绪→大脑切换模式→情绪平息"的机制画成一眼懂的隐喻
- 尺寸：1024x1024
- 完整提示词：

```
温暖人文风格的扁平插画，方形构图，柔和手绘质感，用一个隐喻把心理机制画出来，不要任何文字。

要表达的核心机制：一团翻涌的情绪风暴，当它被"说出来/命名"之后，慢慢变成了一朵可以被看见、被握住的温暖小云朵——情绪没有消失，但它被驯服了，变得可以被处理。

画面隐喻：
- 左边/上方：一个小孩胸口或头顶有一团翻涌的、颜色混乱的情绪风暴（用漩涡、乱线、深色调表达"情绪在转圈、越来越强"）
- 中间：一个小小的"说话"动作——可以是一个小嘴巴张开、一个对话气泡（气泡里是抽象的波浪线，不是文字），表示"情绪被说出来了"
- 右边/下方：同一个小孩，胸口或手里捧着一朵柔软的、颜色温暖的小云朵——情绪变成了可以被看见、被握住的东西，不再是失控的风暴
- 整体有一种"从混乱到平静"的流动感，但不是"情绪消失了"，而是"情绪被接住了"

情绪基调：从混乱到被接纳，温柔而有力量

配色方案：
- 情绪风暴：深蓝紫、灰蓝（混乱感）
- 被命名后的云朵：珊瑚橙 #f0875a、暖黄、柔和的粉
- 背景奶油白 #fffbf0，干净
- 整体从左冷到右暖的色彩流动

风格要求：
- 扁平插画 + 手绘质感，柔软有温度
- 隐喻清晰，普通家长一眼能看懂"情绪从风暴变成了可以握住的云朵"
- 人文温暖，不要冷硬、不要恐怖

不要出现：
- 真实照片级人脸
- 冷硬扁平矢量图标风、3D 渲染、霓虹光效

输出：PNG，高清。
```
