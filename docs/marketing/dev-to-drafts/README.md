## Dev.to 推广合规要点

- **必须披露**：在文章末尾用 italics 标注 referral disclosure，例如：
  > *Disclosure: The registration link is a referral link. I receive a 10% commission on future top-ups. You can register directly at llm-link.top to avoid this.*
- 不要在标题塞促销词（"FREE"、"DISCOUNT"、"SALE"），否则触发反垃圾过滤
- 文章正文中可有 1-2 个推广链接，不要全文链接堆砌
- tags 控制在 4 个以内，相关性强
