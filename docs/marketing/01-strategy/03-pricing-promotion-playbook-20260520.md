## 三、LLM-Link 定价方案（定稿）

### 3.1 基础充值比例

**¥1 = $1 额度**（不动，对标 PackyCode 诚实派）

- 理由：避免"玄学汇率"舆情风险，后期调整空间大
- 话术：「充值 ¥100 到账 $100 额度」

### 3.2 充值5折（核心促销）

**全场充值即享5折优惠**（即充值金额双倍到账额度）

| 充值档位 | 实际到账 | 折算单价 |
|---------|---------|---------|
| ¥10 | $20 | ¥0.5/$1 |
| ¥50 | $100 | ¥0.5/$1 |
| ¥100 | $200 | ¥0.5/$1 |
| ¥200 | $400 | ¥0.5/$1 |
| ¥500 | $1000 | ¥0.5/$1 |

**规则**：
- 所有用户、所有充值档位均适用
- 活动期 30 天（D1-D30）
- 与长期返利可叠加，与其他活动不叠加

### 3.3 分组倍率（技术叙事层）

| 分组 | 倍率 | 说明 |
|------|------|------|
| default | 1.0x | 官方对标价 |
| cc-sale | 0.8x | Claude Code 专用优惠渠道 |
| codex-sale | 0.35x | Codex 专用优惠渠道 |
| opus-sale | 0.5x | Opus 4.6 优惠渠道 |

**话术**：「选对分组，实际调用成本再降 50-65%」

### 3.4 三层叠加算例表（必须配套）

**示例：充 ¥200 + cc-sale 分组**

```
第一层：充值 ¥200
第二层：充值5折（双倍到账） → 到账 $400 额度
第三层：cc-sale 分组 0.8x 倍率 → 等效 $500 调用算力
折算：¥200 ÷ $500 = ¥0.40/$1 等效调用成本
- Claude Sonnet 4.6 官方价：$3/百万 input tokens
- LLM-Link 折算后：¥0.60/百万 tokens（约 $0.08，官方 2.6%）

## 五、邀请裂变机制（简单有效）

### 5.1 双向激励（保持现状）

**邀请人**：
- 被邀请人首充 ≥ ¥50 → 立即奖励 ¥10 额度
- 长期返利：被邀请人消费的 10%（30 天到账）

**被邀请人**：
- 注册即送 ¥5 体验额度
- 首充享受充值5折（双倍到账）

### 5.2 发放方式

**手工发放 SOP**（每天晚间 21:00）：
1. 后台查看当日新增首充用户
2. 查询邀请人（通过 aff 关系）
3. 筛选"被邀请人首充 ≥ ¥50"
4. 手动给邀请人账户增加 ¥10 额度
5. 记录到 `invite-reward-log.csv`
6. 群里 @ 邀请人通知

### 5.3 为什么不做复杂阶梯？

- ❌ 阶梯返佣（1-5人10%，6-20人15%）→ 用户算不清，运营维护成本高
- ❌ KOC 分销计划 → 一期目标 30-50 人，不需要
- ✅ 简单双向激励 → 用户秒懂，运营手工可控

## 七、风险控制

### 7.1 合规风险

**风险点**：被举报"虚假宣传""价格欺诈"

**应对**：
1. 所有文案必须附算例表，可核验
2. 用"折算约等于""以到账为准"，避免"汇率承诺"
3. 活动规则写明"首充限一次""活动期 30 天"
4. 后台记录所有充值赠送明细，可随时提供证据

### 7.2 薅羊毛风险

**风险点**：批量注册刷首充赠送

**应对**：
1. 首充赠送每用户限一次（后台强制）
2. 同一支付账号/同一邀请人短时间 ≥ 3 单 → 人工核查
3. 单笔上限 ¥500，控制单次损失
4. 邀请奖励手工发放，可人工拦截异常

### 7.3 舆情风险

**风险点**：后期调价被骂"割韭菜"

**应对**：
1. 明确标注"活动期 30 天"，不承诺永久
2. 基础比例 ¥1=$1 不动，只调整赠送比例
3. 调价前 7 天群内预告，给老用户缓冲期

## 十、常见问题

**Q1：为什么不直接做 ¥0.5 = $1？**  
A1：行业已有 ¥0.059 = $1（FoxCode），¥0.5 不够亮眼且容易触发"跑路盘"联想。用阶梯赠送 + 分组倍率组合，最终折算可达 ¥0.25/$1，更有技术叙事支撑。

**Q2：为什么不做复杂的阶梯返佣？**  
A2：一期目标 30-50 人，不需要复杂裂变机制。简单双向激励（邀请奖 ¥10 + 长期 5%）用户秒懂，运营手工可控。

**Q3：如何防止被举报虚假宣传？**  
A3：所有文案必须附算例表，用"折算约等于""以到账为准"，避免"汇率承诺"。后台记录所有充值赠送明细，可随时提供证据。

**Q4：充值5折会不会亏？**  
A4：一期目标 30-50 人，¥10-500 全档位双倍到账，成本可控。大额充值用户通常是重度用户，LTV 高，长期不亏。

**Q5：后期如何调价？**  
A5：基础比例 ¥1=$1 不动，只调整折扣比例（如从5折改为6折或7折）。调价前 7 天群内预告，给老用户缓冲期。
