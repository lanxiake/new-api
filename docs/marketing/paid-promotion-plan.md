## 三、渠道分配与定位

### 主力：小红书 KOC 素人笔记（¥1000）

**为什么**：AI 工具种草氛围最好、单价低、可批量铺、用户决策链短。

**人群定位**：
- 程序员博主（写代码 / 接外包 / 独立开发）
- AI 工具测评博主（不限技术深度，能讲清楚"省钱"即可）
- 大学生计算机方向（毕设、学习用 AI 编程）

**投放节奏**：
- 第 1 周：试投 4 个 KOC，每人 1 篇，¥80–120/篇
- 第 2 周：根据第 1 周数据，加投 4 个表现接近的 KOC
- 第 3 周：第 15 天复盘后，把表现最好的 1–2 个 KOC 续约 1 篇（用备用预算）
- 第 4 周：维护互动 + 让已转化用户晒单（免费 UGC）

**爆款判定**：3 天内点赞 ≥ 50 + 评论 ≥ 10 + 收藏 ≥ 20 → 进入续约名单。

### 辅助：微信公众号软文（¥500）

**为什么**：技术受众精准、长内容承载力强、可沉淀到公众号粉丝池。

**目标号**：
- 5k–2w 粉的 AI 工具号 / 程序员资讯号 / 独立开发者号
- 避开百万级大号（一篇 ¥3000+，超预算）
- 头条 ¥800–2000，次条 ¥300–800，本期只投次条

**投放节奏**：
- 第 1 周末：投 1 个号（次条，¥300）
- 第 3 周初：投 1 个号（次条，¥200）
- 不追求阅读量，追求文末"识别二维码进群"的扫码率

### 不投：抖音、B 站、信息流

理由见上文。本期不动，下期再评估。

## 五、第 15 天中期调优 — 决策树

```
看 CAC：
├─ ≤ ¥40 → 维持节奏，按计划复投
├─ ¥40–¥60 → 砍掉表现差的 KOC，把剩余预算压在前 3 名
├─ ¥60–¥80 → 警告线：暂停新投，分析问题（素材？落地？群运营？）
└─ > ¥80 → 停损：剩余预算改投"邀请始付始奖"加码（¥20/人）

看进群率：
├─ ≥ 60% → 承接话术 OK
├─ 40%–60% → 优化笔记末尾引导文案 + 群二维码露出
└─ < 40% → 落地路径有问题，可能需要改成"先加企微再进群"

看付费率（进群后 7 天内首充）：
├─ ≥ 30% → 群运营有效
├─ 15%–30% → 加码群内活动（限时充50送50加码、晒单返红包）
└─ < 15% → 群内话术需要重写，参考 private-traffic-ops.md
```

## 七、关键风险与对策

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| KOC 笔记限流（违禁词） | 高 | 中 | 避开"Claude""ChatGPT""API"等敏感词，用"AI编程工具""中转站"代替；详见 [creatives-paid.md](./creatives-paid.md#违禁词清单) |
| 微信群被封（广告嫌疑） | 中 | 高 | 群名不带"福利""优惠"；前 2 天禁言；群主用小号；备份群二维码定期更换 |
| CAC 超标 | 中 | 高 | 第 15 天硬停损，剩余预算改投裂变 |
| 进群不付费 | 中 | 高 | 群运营 SOP，限时活动逼单 |
| KOC 收钱不发 | 低 | 中 | 一律发布后付款，要求带专属链接截图 |
| 假流量 / 刷数据 | 中 | 中 | 只看进群 + 付费转化，不看播放/点赞 |
