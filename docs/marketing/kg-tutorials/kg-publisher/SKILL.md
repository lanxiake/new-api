# kg-publisher · 多平台发布技能

## 一、排版组装规范

AI 生成的原始底图为**纯视觉图（无任何文字）**，需叠加文字层后才是最终成品图。

### 1.1 每张图的文字层清单

```
┌──────────────────────────────────────┐
│ MT图解百科 · 第X页/共N页             │ ← 顶部品牌标签（小字，品牌色）
│                                      │
│ [大标题]（2-6字，粗体白色）          │ ← 主标题区（顶部留白区内）
│ [反直觉副标题]（细体，辅助色）       │
│ ── ENGLISH SUBTITLE ──               │ ← 英文装饰行（半透明小字）
│                                      │
│ [AI生成的3D写实场景底图]             │ ← 主视觉区
│                                      │
│ ①元素名：说明  ②元素名：说明        │ ← 标注层（引线+文字）
│                                      │
│ ■ 总结  [一句话核心结论]             │ ← 底部总结条（深色底白字）
│ ─── MT图解百科 · 系列名 ───         │ ← 版权/系列小字
└──────────────────────────────────────┘
```

### 1.2 标注样式规范

- **标注线**：细直线 1-2px，端点小实心圆点
- **引出方向**：从主体结构引向图片空白边缘区，不遮挡核心视觉
- **文字大小**：12-14px
- **颜色**：深色底图用白色；浅色底图用深蓝（`#1a3a5c`）
- **数量**：每张图 5-10 个标注点，不超过 12 个

### 1.3 总结条文案格式

```
总结  [主体]通过[核心机制A]、[核心机制B]与[核心机制C]，[一句话结论]。
```

## 二、发布文件格式

### 2.1 wechat.md（公众号版）

```markdown
---
title: 【MT图解百科】{主体名称}——{系列副标题}
author: MT图解百科
summary: {≤120字摘要，含本系列N张图覆盖的核心知识点，让读者决定是否点开}
cover: images/01-cover.png
series: MT图解百科
---

{科普正文，每张图对应一段100-200字说明，口语化语气}

![{第1张标题}](images/01-cover.png)

{第1张科普说明，来自 outline.md 的"科普说明"字段}

![{第2张标题}](images/02-xxx.png)

{第2张科普说明}

...（以此类推）

---

💡 **本期MT图解百科，你学到了什么？评论告诉我👇**

> 下期预告：{下一个主体预告}
```

## 三、公众号发布脚本

```bash
cd kg-tutorials

# Git Bash / macOS / Linux
WECHAT_APP_ID="wx..." WECHAT_APP_SECRET="..." \
  python skills/kg-publisher/scripts/publish_wechat.py \
  "series/<slug>/publish/wechat.md"

# Windows PowerShell（先设环境变量）
python skills/kg-publisher/scripts/publish_wechat.py \
  "E:\...\series\<slug>\publish\wechat.md"
```

**成功标志**：
```
[OK] draft saved! media_id=dGPp3Khw-...
login mp.weixin.qq.com -> content management -> drafts to review and publish
```

脚本只存草稿，**不自动群发**，人工在后台审核后再推送。

## 四、小红书发布（手动）

1. 打开 `series/<slug>/publish/xhs.md`，复制文案
2. 打开小红书创作者中心
3. 上传图片：封面图（1张）+ 正文图（N-1张），按顺序
4. 粘贴文案，调整话题标签
5. 设置发布时间（建议早8-9点或晚8-10点）

## 五、质量自检（发布前）

- [ ] 每张图已完成排版（文字层已叠加，非原始底图）
- [ ] 总结条文案与图片内容匹配
- [ ] 公众号文案摘要 ≤120字
- [ ] 小红书文案含5个以上话题标签
- [ ] 封面图尺寸适合公众号（建议宽900px以上）
