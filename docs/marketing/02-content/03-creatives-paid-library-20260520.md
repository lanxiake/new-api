## 九、应急预案

### 笔记被限流 / 删除

**原因**：
- 违规词（最好、第一、必备）
- 引流过于明显（链接 / 二维码）
- 被举报（竞品恶意）

**应对**：
- 立即联系 KOC 修改 / 申诉
- 备用话术：把链接改成"私信我"
- 备用引流：引导加个人微信 → 再发链接

### 转化率突然下降

**原因**：
- 素材疲劳（用户看腻了）
- 竞品活动（更大力度）
- 产品问题（服务不稳定）

**应对**：
- 立即启动新模板（换个角度）
- 加码活动（邀请始付始奖提升到 ¥20）
- 排查产品（检查 API 稳定性）

### KOC 数据造假

**识别**：
- 浏览量很高，但进群人数为 0
- 点赞 / 收藏比例异常（> 10%）
- 评论区全是机器人

**应对**：
- 拒绝结算
- 拉黑该 KOC
- 下次合作要求先看历史数据
