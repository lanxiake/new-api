## 一、合作模式总览

| 模式 | 单价 | 周期 | 风险 | 备注 |
|------|------|------|------|------|
| **小红书 KOC 软植入** | ¥80–150/篇 | 单次买断 | 低 | 主力，本期 8–12 单 |
| **公众号次条软文** | ¥300–800/篇 | 单次买断 | 中 | 1–2 篇即可 |
| **CPS 长期合作**（10% 分成 + 0 现金） | ¥0 现金 | 长期 | 极低 | 优先尝试，谈成一个赚一个 |
| 不做：直播带货 / 视频深度合作 | — | — | — | 单价超预算 |

> **优先级**：先谈 CPS（0 现金成本），谈不成再付现金买断。绝大多数 KOC 会拒绝纯 CPS，但 5%–10% 会接受，能省就省。

## 二、找人渠道

### 小红书 KOC

**搜索词**（在小红书 App 内）：
- "AI 编程" / "Claude Code" / "AI 工具推荐" / "程序员 AI" / "Cursor"
- "独立开发者" / "接外包" / "副业开发"
- "代码助手" / "AI 写代码"

**筛选标准**：
- 粉丝 1k–10k（素人区间，单价低，互动率高）
- 近 30 天有更新（活跃度）
- 至少有 1 条互动 ≥ 30 的笔记（说明有内容能力）
- 简介或主页提"接广""合作"（已开通商业能力）

**避开**：
- 粉丝 > 5w 的（单价跳到 ¥500+）
- 笔记全是软广（用户已疲劳）
- 互动数据明显刷量（点赞高但评论空）

### 微信公众号

**找号渠道**：
- 西瓜数据 / 新榜（看历史投放报价，免费版够用）
- 朋友圈打听同行投过哪个号
- 搜公众号关键词："AI 编程" / "程序员" / "独立开发者" / "AI 工具"

**筛选标准**：
- 5k–2w 粉丝（精准号，性价比最高）
- 近 4 篇阅读量稳定（不是单篇爆款拉平均）
- 头条阅读量 > 粉丝数 30%（活跃度健康）
- 接受次条投放（头条超预算）

## 四、合作条款（统一）

### 现金买断

| 项目 | 内容 |
|------|------|
| 价格 | 见上表，最终以单次议价为准 |
| 内容形式 | 软植入，不要求硬广。可以是经验分享、对比测评、踩坑记录 |
| 必带元素 | ① 专属邀请链接 或 邀请码 ② 进群引导（QQ 群号 或 微信群二维码截图）③ "充50送50" 活动提及 |
| 禁用词 | "Claude"（小红书敏感）→ 用"AI 编程助手"；"API"（限流）→ 用"开发工具"；"便宜""最低价"→ 用"省钱""划算" |
| 发布时间 | 工作日 19:00–22:00 或周末 10:00–12:00 |
| 数据要求 | 发布 24h 内截图初始数据（浏览/点赞/收藏） |
| **付款时机** | **笔记/文章发布且通过审核后 24h 内付款**，不接受预付 |
| 不通过条款 | 笔记被限流（24h 浏览 < 100）或被删，全额退款；非创作者过错除外 |
| 续约 | 数据达标（见 [paid-promotion-plan.md 爆款判定](./paid-promotion-plan.md#主力小红书-koc-素人笔记1000)）可续 1 篇，单价不变 |

### CPS 长期合作

| 项目 | 内容 |
|------|------|
| 分成 | 10%，与平台标准 aff 一致（30 天到账） |
| 现金 | ¥0 |
| 体验额度 | 注册后赠送 ¥100 体验额度 |
| 内容要求 | 无强制，自主决定何时发、发什么 |
| 结算 | 通过平台 aff 后台自动结算，可提现到微信/支付宝 |
| 升级 | 若 30 天累计带来 ≥ 10 个付费用户，可升级为"现金 ¥200/月固定费 + 10%分成" |
