# 服务特定条款

**生效日期：** 2025年10月30日

本条款补充 LLM-Link 基础服务协议，涵盖以下特定服务领域。

## 工作版服务要求

客户必须告知用户他们正在使用托管服务产品，且使用受 LLM-Link 政策约束。

## 测试版服务

测试阶段的服务按「现状」提供，LLM-Link 对客户使用测试服务不负责。责任限额为 ¥1,000 或前 12 个月费用的较小者。

## 模型定制

客户可使用微调服务进行模型定制，使用自己提供的数据，该数据属于客户内容。

## 云托管

服务通过主流云平台托管。客户必须遵守云服务商政策，LLM-Link 不对云平台或云服务商的服务负责。

## API 限制

客户受速率限制、配额上限和缓存政策约束。具体限制请参考控制台中的配置说明。

## 服务可用性

目标月度正常运行时间为 **99.9%**，计划维护将提前通知。

## 条款更新

重大变更将提前通知，在 **30 天**后生效。
