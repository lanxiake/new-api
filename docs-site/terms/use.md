# 支持的国家和地区

**生效日期：** 2025年10月30日

LLM-Link 保留不向支持地区列表以外的实体提供产品或服务的权利。

## 覆盖范围

LLM-Link 目前支持在全球 **175 个**国家、地区提供商业 API 访问，包括：

- 美国、加拿大
- 欧盟各成员国
- 日本、印度、韩国、新加坡、澳大利亚
- 以及其他主要市场

## 特别说明

乌克兰的以下地区暂不提供服务：克里米亚、顿涅茨克、赫尔松、卢甘斯克和扎波罗热地区。

## 列表更新

支持地区列表可能定期更新。如你所在地区未在列表中，请联系 LLM-Link 支持团队了解服务可用性。
