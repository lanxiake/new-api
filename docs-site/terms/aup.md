# 使用政策（AUP）

**生效日期：** 2025年10月30日

本政策适用于任何向 LLM-Link 产品/服务提交输入的人，旨在帮助用户保持安全并促进负责任使用。

## 通用使用标准

以下行为**严格禁止**：

1. **违法活动** — 不得违反法律或从事任何违法用途
2. **基础设施危害** — 危害电信、医疗、能源等关键系统
3. **网络安全威胁** — 开发恶意软件或未授权访问系统
4. **武器开发** — 设计武器、军事应用或监控技术
5. **暴力与仇恨** — 煽动极端暴力或基于身份的仇恨内容
6. **隐私侵犯** — 追踪、骚扰或身份盗窃行为
7. **儿童保护** — 禁止任何形式的儿童性虐待内容（含 CSAM）
8. **心理伤害** — 自动生成促进自残/自杀的内容
9. **虚假信息** — 大规模传播误导性内容
10. **民主破坏** — 干扰选举或进行政治宣传
11. **执法滥用** — 用于预测性警务或大规模监控
12. **欺诈行为** — 冒充他人或从事诈骗活动
13. **平台滥用** — 绕过安全保护措施或违反使用限制
14. **露骨内容** — 禁止生成性露骨内容

## 高风险用例要求

涉及以下领域的应用需实施额外保护措施：

| 领域 | 要求 |
|------|------|
| 法律、医疗、保险、金融 | 需「人在回路」审查及用户披露 |
| 就业、住房、教育认证 | 需合格专业人员审核决策 |
| 新闻媒体内容 | 自动生成内容须标注 AI 参与 |

**必要措施说明：**
- **人在回路**：合格专业人员须在提供建议前进行审查
- **披露**：必须告知用户正在使用 AI 辅助生成内容

## 其他使用指南

- 消费者聊天机器人须披露 AI 互动身份
- 面向未成年人的产品须遵守额外指南
- 代理用例须完整遵守所有政策
- MCP 服务器须遵守目录政策

如有疑问，请联系 LLM-Link 支持团队。
