# 模型广场介绍

## 如何查看最新分组

在控制台面板，点击右上角「模型广场」，即可进入分组与模型的查看页面。

- 左侧侧边栏显示所有**令牌分组**
- 右侧显示该分组下的**可用模型**
- 分组名称旁边的数字为**价格倍率**

## 价格倍率说明

| 倍率 | 含义 |
|------|------|
| 低于 1x（如 0.8x） | 享受折扣，价格更低 |
| 等于 1x | 按基准价格计费 |
| 高于 1x（如 1.5x） | 高于基准价格，通常为官方渠道 |

::: tip
建议在配置 CLI 工具前，先浏览模型广场，了解各分组下的具体模型名称，避免配置时出现「模型不存在」的错误。
:::
