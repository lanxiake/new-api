# Banana2 Pro 绘图教程

本教程介绍如何通过 Cherry Studio 使用 Banana2 Pro 绘图模型。

## 配置步骤

1. 在 [LLM-Link 控制台](https://www.llm-link.top) 创建 **Gemini 分组**的令牌，复制 ApiKey

2. 前往 [Cherry Studio 官网](https://cherry-ai.com) 下载并安装 Cherry Studio

3. 打开 Cherry Studio，进入「设置」

4. 点击「模型服务」，选择「添加」以新增供应商

5. 在新建供应商窗口中，填写供应商名称，类型选择对应格式

6. 填写以下信息：
   - **API Key**：粘贴你的 ApiKey
   - **API 地址**：`https://www.llm-link.top`

7. 点击「管理模型」，搜索并添加 **Banana2 Pro** 绘图模型（该模型已针对常见宽高比优化）

8. 确认模型添加成功

9. 返回首页，进入「助手设置」，关闭「流式输出」

10. 在模型设置中选择刚创建的绘图模型

11. 开始创作图片

::: tip
Banana2 Pro 已针对多种常见宽高比进行优化，开箱即用效果良好。
:::
