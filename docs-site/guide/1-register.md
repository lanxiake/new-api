# 注册账号

欢迎使用 LLM-Link！请在 [llm-link.top/register](https://www.llm-link.top/register) 完成账号注册。

![注册页面](/images/guide/register-page.png)

## 注册方式

### 方式一（推荐）：github 账号

点击「使用 github 继续」，在弹出窗口中授权 github 账号，系统将自动完成注册并登录，无需设置密码。

![github 授权登录示意](/images/guide/register-google.png)

### 方式二：邮箱注册

选择「使用用户名注册」，填写以下信息后提交：

- 邮箱地址
- 用户名
- 密码（建议包含字母、数字和特殊字符）

::: warning 安全提示
请妥善保管登录凭据，防止账号被盗用。
:::

## 下一步

注册完成后，继续 [登录账号](./2-login)。
