# 注册账号

欢迎使用 LLM-Link！请在 [llm-link.top/register](https://www.llm-link.top/register) 完成账号注册。

![注册页面](/images/guide/register-page.png)

## 注册方式

LLM-Link 当前支持 **GitHub 一键授权** 和 **用户名 + 邮箱** 两种注册方式。

### 方式一（推荐）：GitHub 账号

点击「使用 GitHub 继续」，在弹出窗口中授权 GitHub 账号，系统将自动完成注册并登录，无需设置密码。

### 方式二：用户名注册

选择「使用 用户名 注册」，填写以下信息后提交：

- 用户名
- 密码（建议包含字母、数字和特殊字符）
- 邮箱地址（用于找回密码）

::: tip 邮箱验证
首次登录后建议在「个人设置」中绑定并验证邮箱，便于后续找回密码与接收通知。
:::

::: warning 安全提示
请妥善保管登录凭据，防止账号被盗用。
:::
