# 购买额度

登录控制台后，在「钱包管理」页面进行在线充值。

## 兑换比例

平台采用 **1:1** 的兑换比例，即 1 元人民币 = 1 美元的额度价值。

## 充值步骤

1. 登录 [LLM-Link 控制台](https://www.llm-link.top)
2. 点击左侧菜单「钱包管理」，或直接访问 [llm-link.top/console/topup](https://www.llm-link.top/console/topup)
3. 输入兑换码或选择充值金额，完成支付

![钱包管理页面](/images/guide/wallet-page.png)

::: tip 建议
首次充值可先充值少量金额（如 10 元）进行测试，确认接入正常后再按需充值。
:::

::: tip 通过邀请获得返利
通过他人邀请链接注册的账号，每次充值都会让邀请人获得按比例返利。如您也希望邀请好友享受这份奖励，请阅读 [邀请奖励](./6-invite)。
:::
