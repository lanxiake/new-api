# 登录账号

访问 [llm-link.top/login](https://www.llm-link.top/login) 登录控制台。

![登录页面](/images/guide/login-page.png)

## 登录方式

### GitHub 账号登录

点击「使用 GitHub 继续」，选择注册时绑定的 GitHub 账号，授权后即可自动登录。

### 邮箱 / 用户名登录

点击「使用 邮箱或用户名 登录」，依次填写用户名或邮箱、密码，点击「继续」即可。

::: tip 登录状态
浏览器会保持登录状态；在新设备上需重复登录流程。
:::

## 下一步

登录成功后，继续 [购买额度](./3-quota)。
