# 邀请奖励

LLM-Link 提供完整的邀请返利机制：邀请好友注册并充值，您可获得**充值金额按比例**的返利积分，过待结算期后自动到账并可划转到主账户余额消费。

## 一图概览流程

```
分享邀请链接 ──► 好友通过链接注册 ──► 好友首次/任意一次充值
       │                                      │
       │                                      ▼
       │                            后端按比例创建返利记录
       │                            （状态：待到账）
       ▼                                      │
查看「邀请奖励」页统计                          ▼
       │                            过 N 天解冻期后
       │                            状态变为「已到账」
       ▼                                      │
点击「划转到余额」                              │
转入账户主余额                                  ◄── 出现在「可用余额」
```

## 步骤一：获取邀请链接

1. 登录 [LLM-Link 控制台](https://www.llm-link.top)
2. 点击左侧菜单「邀请奖励」，或直接访问 [llm-link.top/console/invite-rewards](https://www.llm-link.top/console/invite-rewards)
3. 在页面顶部「我的邀请链接」处，点击右侧「复制」按钮即可

邀请链接形如：

```
https://www.llm-link.top/register?aff=ABC123
```

链接尾部 `aff=` 即您的专属邀请码，分享给好友后**自动绑定关系**，无需对方手动填写。

## 步骤二：好友通过链接注册

好友打开您分享的链接后：

- 注册页的「邀请码」字段会**自动锁定**为您的邀请码（不可修改）
- 完成账号信息填写后即可提交，邀请关系建立成功

::: tip 邀请关系唯一
每个用户在系统内只允许有一个邀请人。一旦绑定，无法更改或迁移给其他邀请人。
:::

::: warning 必须通过邀请链接进入
如果好友直接打开 `register` 页且系统开启了「邀请注册」开关，必须手动填写邀请码才能完成注册，否则提交按钮会保持禁用。
:::

## 步骤三：好友充值后获得返利

好友每一笔成功充值，系统都会按当前**返利比例**为您创建一条返利记录：

| 字段 | 含义 |
|------|------|
| 充值金额 | 好友本次实际到账额度 |
| 返利金额 | `充值金额 × 返利比例` |
| 比例 | 返利记录创建时的快照比例（不受后续设置变更影响） |
| 状态 | 初始为「待到账」 |
| 应到账时间 | 创建时间 + 待结算天数 |

返利不会立即到账，需要经过**待结算期**（默认 30 天）。这是为了避免好友退款 / 异常订单触发的不当返利。

## 步骤四：到达解冻期，自动到账

到达「应到账时间」后，定时任务会自动将该笔返利的状态更新为「已到账」，并将返利金额加到您的「可用余额」上。

您可以在「邀请奖励」页：

- **顶部统计卡** 实时查看：
  - 可用余额：可立即划转的部分
  - 待结算：尚在解冻期的部分
  - 历史总计：累计获得的返利总额
  - 邀请人数：成功通过您链接注册的用户数
- **邀请记录** Tab：分页查看每位被邀请人的累计贡献额
- **返利明细** Tab：分页查看每一笔返利记录的状态、金额、时间

## 步骤五：划转到余额

「可用余额」需要**手动划转**到主账户余额后才能用于消费。

操作方式：

1. 在「邀请奖励」页右上角点击「划转到余额」按钮
2. 在弹窗中填写要划转的额度（最低为 1 美元额度对应的 quota 单位）
3. 点击「确定」提交，划转成功后主账户余额立即增加

::: tip 划转无次数限制
您可以随时多次划转，每次最低 1 美元额度。划转后的额度等同于充值额度，可调用任意分组下的模型。
:::

## 常见问题

**Q：好友之前已经注册过，现在通过我的链接再点一次能绑定关系吗？**
A：不能。邀请关系仅在好友**首次注册**时绑定，已注册账号无法补绑。

**Q：返利比例是多少？**
A：默认 10%，具体比例由管理员后台设置，可能根据运营活动调整。返利记录创建时会快照当时比例，后续比例变更不影响历史记录。

**Q：待结算期可以缩短吗？**
A：默认 30 天，由管理员配置。该参数主要用于风控，不建议缩短。

**Q：好友退款了，已经发放的返利会扣回吗？**
A：当前版本：「待到账」状态下的返利可被取消；「已到账」后不会自动扣回，请避免恶意刷单。

**Q：什么情况下「划转到余额」按钮是禁用的？**
A：当「可用余额」为 0 时禁用。如果显示有余额却仍禁用，可刷新页面重新拉取最新数据。
