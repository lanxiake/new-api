# 配置 CLI 工具

LLM-Link 支持 Claude Code、Codex 和 Gemini 三种主流 CLI 工具。

## 推荐方式：使用 CC-Switch

我们强烈推荐使用 [CC-Switch](https://github.com/farion1231/cc-switch) 工具来配置使用环境，操作简单便捷。

请参考以下教程：

- [通用步骤](/cc-switch/1-common)
- [Claude Code 配置](/cc-switch/2-claude)
- [Codex 配置](/cc-switch/3-codex)
- [Gemini 配置](/cc-switch/4-gemini)

## 手动配置方式

如需手动配置，请先完成环境检查，再按对应工具的教程操作：

- [环境检查（通用步骤）](/cli-config/1-env)
- [Claude Code 手动配置](/cli-config/2-claude)
- [Codex 手动配置](/cli-config/3-codex)
- [Gemini 手动配置](/cli-config/4-gemini)

::: warning 请务必先检查环境！！！
在配置任何 CLI 工具之前，**请务必先完成** [环境检查](/cli-config/1-env) 步骤。
:::
